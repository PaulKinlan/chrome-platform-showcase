The light-math it fixes

Two equal lights on the same spot make twice the light. A gamma-encoded canvas doesn't know that: "lighter" adds the encoded numbers, and 50%-gray plus 50%-gray blows out to near-white. On a linear canvas the same call adds actual light. Both halves of that claim are measurable, and one of them works in every browser you own.

Ships in Chrome 155. The "native linear canvas" panels below run only where getContext('2d', { colorSpace: 'srgb-linear' }) really succeeds — Chrome 155, or Canary with --enable-blink-features=ColorSpacePredefinedLinearSpaces or chrome://flags/#enable-experimental-web-platform-features. Everything else on this page is ordinary today-canvas plus arithmetic.

Two lights, added

Both circles are the same flat gray, composited with globalCompositeOperation = "lighter", which adds pixel values. Where they overlap, physics says the luminances add. Drag the intensities and watch the overlap patch — then read the sampled numbers, because the two left panels can look deceptively alike until you push both lights past 40%.

// The transfer functions the linear canvas applies for you (IEC 61966-2-1):
const toLinear   = v => v <= 0.04045  ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4;
const fromLinear = v => v <= 0.0031308 ? v * 12.92 : 1.055 * v ** (1 / 2.4) - 0.055;
// Physically-correct addition of two lights:
overlap = fromLinear(min(1, toLinear(a) + toLinear(b)))

Shrink a checkerboard

A one-pixel black/white checkerboard is exactly half light. Downscale it 8× with drawImage and every output pixel should be 50% luminance — sRGB value 188. A gamma canvas averages the code values instead and lands near 127, visibly too dark. This is the "decimation" case from the feature's own motivation, and it is why downscaled thumbnails of fine detail look muddy.

What this does not change: gradients

You might expect a red→green gradient to lose its muddy middle on a linear canvas. Measured: it does not. Canvas gradients interpolate in the gradient's own interpolation space — sRGB by default, per spec — and the result is then stored in the backing space. On an srgb-linear canvas the midpoint of that gradient reads back as linear value 54, which is exactly sRGB 127 converted: the same visual middle. The backing store changes where compositing, blending, and resampling happen, not how gradient stops are mixed. That distinction is what the two stages above demonstrate.
