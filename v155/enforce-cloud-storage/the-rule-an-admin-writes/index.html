v155 · enforce cloud storage

The rule an admin writes

The whole feature is one dropdown in an admin console — a File-download DLP rule whose action, from Chrome 155, can be Enforce cloud storage. Compose the rule below from its real parts and read what it does to a user's next download, narrated with the exact enum values and UI strings Chromium uses on the way.

This is an illustration, not the console. The fields, tags and behaviours below are taken from the published OnFileDownloadedEnterpriseConnector policy schema and Chromium source (cited step by step). Nothing on this page executes, applies, or detects policy — a real rule is written in the Google Admin console and enforced by the browser on managed profiles.
