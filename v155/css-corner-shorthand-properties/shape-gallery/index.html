v155 · corner shorthands

Shape gallery

Every corner-shape value on the same box at the same radius. The radius is what the corner consumes; the shape is what it does with that space — which is why every one of these is the same size and none of them is the same silhouette.

All the shapes

Take the radius to zero and every shape collapses to a square corner — there is no space for the shape to happen in. That is the relationship: the radius is the budget, the shape is how it is spent.
