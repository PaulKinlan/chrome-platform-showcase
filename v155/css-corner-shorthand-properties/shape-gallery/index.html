Shape gallery

Compare the six corner-shape keywords and a superellipse(2) example at one radius. The keywords give named shapes; the function takes a numeric parameter. squircle and superellipse(2) are equivalent, so those two examples deliberately match.

Keywords and a function

At radius zero, all corners are square. Otherwise, the supported shapes use the area set by border-radius; square keeps a square corner. The support count checks corner-shape values, not the newer corner shorthands tested below.
