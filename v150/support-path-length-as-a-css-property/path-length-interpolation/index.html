Interpolating path-length Itself

The whole point of promoting pathLength to CSS: the property's spec'd animation type is by computed value, so two numeric values interpolate smoothly with transition and @keyframes. Here the animated value is path-length — not stroke-dashoffset — and you watch getComputedStyle() report the intermediate lengths while a fixed stroke-dasharray: 250 visibly re-scales.

choose the interpolation endpoints

Both demos below interpolate path-length between endpoint A and endpoint B. The dash value stays fixed at 250, so the drawn fraction is 250 / path-length — as the property animates, the arc visibly grows or shrinks.

path-length: 500 → dash 250/500 = 50% drawn
path-length: 2000 → dash 250/2000 = 13% drawn

transition: path-length

@keyframes on path-length

A keyframes rule oscillates path-length between the same endpoints (fed in via custom properties): from { path-length: var(--pl-a) } to { path-length: var(--pl-b) }. The identical animation also runs on the wave that a <textPath> follows — its startOffset="150" is in user units of the normalized length, so the text physically slides along the wave as the property animates. Dash and text-on-a-path are both spec'd consequences of path-length.

edge case: none does not interpolate

"By computed value" interpolation only works when both endpoints are numbers. The initial value none is a keyword, so a transition from none to a number is discrete — the computed value must flip at the transition midpoint with no intermediate numbers. This probe runs that transition and logs every distinct sampled value; a genuine implementation shows exactly two: none, then the target number.

code

/* Animation type (SVG 2 propdef): "by computed value"
   → number ↔ number interpolates; none ↔ number is discrete. */

circle {
  stroke-dasharray: 250;                     /* fixed dash…            */
  path-length: 500;                          /* …drawn fraction 50%    */
  transition: path-length 1500ms ease-in-out;
}
circle.grown { path-length: 2000; }          /* animates to 12.5% drawn */

@keyframes pl-oscillate {
  from { path-length: 500; }
  to   { path-length: 2000; }
}
