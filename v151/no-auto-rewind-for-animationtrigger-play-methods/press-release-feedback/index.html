Press & release feedback

The motivating product case for directional play actions: press swells a chip with play-forwards, release shrinks it with play-backwards — and once the swell has finished, further presses must not rewind it to the start. Hold the button (pointer or keyboard) and hammer it at the finished state to watch the no-auto-rewind contract hold.

The CSS this models

.chip {
  animation: swell 600ms ease-out both;
  /* press trigger plays forward; release plays backward;
     play-forwards on an already-finished forward run is a no-op — no rewind */
  animation-trigger: --press play-forwards play-backwards;
}

Per the spec, play-forwards sets a positive playback rate and calls play(); play-backwards sets a negative rate and calls play(). Chrome 151's change: when the animation has already run to completion in that direction, the play action no longer auto-rewinds it to the start.
