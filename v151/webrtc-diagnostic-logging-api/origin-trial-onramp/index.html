Origin-trial on-ramp

Three gates stand between a page and navigator.rtc: a secure context, the RTCDiagnosticLogging runtime feature (origin-trial token or flag), and — for real log collection in production — the enterprise policy. This page probes the first two in your browser, right now, then builds the exact enrollment snippet for your own origin.

2 · build your enrollment snippet

Register your origin for the RTCDiagnosticLogging trial on the Chrome origin trials console, paste the token below, and copy either delivery form. The generated markup updates as you type — nothing is sent anywhere.

Tokens are long base64 strings bound to your origin and the trial's end milestone.

as an html meta tag

<meta http-equiv="origin-trial" content="YOUR_TOKEN">

as an http response header

Origin-Trial: YOUR_TOKEN

3 · without a token

  • Local development: launch Chrome 151 with --enable-blink-features=RTCDiagnosticLogging (the exact runtime_enabled_features.json5 name), or enable chrome://flags/#enable-experimental-web-platform-features and reload this page — then hit Re-probe above.
  • Enterprise deployment: even with the API exposed, Chrome only collects diagnostic logs for origins listed in the WebRtcDiagnosticLogCollectionAllowedForOrigins policy. The API deliberately never tells the page whether collection was authorized.
  • Secure context: navigator.rtc is [SecureContext] — plain http:// origins (other than localhost) never see it, token or not.
