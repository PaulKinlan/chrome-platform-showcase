Breakpoint Matrix

Five frames at fixed widths — 220, 280, 360, 540, 720 — each running the same comma-separated @container rule. The rule mixes a container-size branch and a style() branch, so one declaration reacts to two completely different axes: how roomy the container is, or a --boost flag you set on it.

the rule

@container tile (min-width: 360px), style(--boost: on) {
  .tile {
    background: emerald-tinted;
    font-family: display;
    font-size: 1.4rem;
  }
}

Both branches are container query features — a size condition and a style() condition — and only one of the two needs to match. (A media feature like prefers-reduced-motion would be an unknown query inside @container: the comma list tolerates it, but that branch always evaluates false — pair @container with @media instead when you need user preferences.)

read it back from CSSOM

const rule = [...document.styleSheets[0].cssRules]
  .find(r => r.constructor.name === 'CSSContainerRule');
console.log(rule.conditionText);
// "tile (min-width: 360px), style(--boost: on)"  (Chrome 150+)
// — on an older browser the comma rule is absent from cssRules entirely.
