The rule mixes a container-size branch and a style() custom-property branch, so a single declaration can be fired by either axis. Toggle the compact flag to fire the style() branch even in the cramped frames.

the rule

@container tile (min-width: 360px), tile style(--compact: on) {
  .tile {
    background: emerald-tinted;
    font-family: display;
    font-size: 1.4rem;
  }
}

The second branch is a style() query on a custom property — a completely different axis from container size, combined with the same comma fall-through semantics as @media lists: only one of the two needs to match. Note that a media condition such as (prefers-reduced-motion: reduce) is not valid inside @container — the comma list tolerates it as an unknown query, but an unknown query never matches, so that branch would be dead. The conformance suite's fallback-with-unknown-feature assertion proves exactly that tolerance.

read it back from CSSOM

const rule = [...document.styleSheets[0].cssRules]
  .find(r => r.constructor.name === 'CSSContainerRule');
console.log(rule.conditionText);
// "tile (min-width: 360px), tile style(--compact: on)"
