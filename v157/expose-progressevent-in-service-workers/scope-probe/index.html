what the worker runs

// inside sw.js
const exposed = typeof self.ProgressEvent === "function";

let fields = null;
if (exposed) {
  const event = new self.ProgressEvent("progress", {
    lengthComputable: true,
    loaded: 512,
    total: 2048,
  });
  fields = {
    lengthComputable: event.lengthComputable,
    loaded: event.loaded,
    total: event.total,
  };
}

port.postMessage({ exposed, fields });

Note that the event itself cannot be posted — an Event is not structured-cloneable — so the worker sends its field values. That is a property of postMessage, not a limitation of the feature: the point is that the worker can build a platform-defined ProgressEvent to read those values from, instead of an object it invented.
