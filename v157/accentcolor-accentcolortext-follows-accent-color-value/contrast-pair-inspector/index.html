The AccentColorText contrast flip

The spec says AccentColorText "takes its value from the contrasting foreground color to AccentColor" — the same pairing the browser uses for the glyphs inside a checked checkbox. Slide one accent from near-black to near-white and watch where this browser flips the text color, with the WCAG 2.x ratio computed live from the two resolved values. Then compare with accent-color: auto (the OS accent) and the newer contrast-color() function.

Everything below is read back from getComputedStyle() — the flip point and ratios describe your browser's pairing, not a hard-coded table. Where the keywords don't parse (pre-157 contexts) the panel reports that state instead of showing fake pairs.

code path

probe.style.accentColor = "oklch(45% 0.13 250)";
fg.style.color = "AccentColorText";          // the UA's paired foreground
bg.style.color = "AccentColor";              // the accent itself

const pair = [getComputedStyle(bg).color, getComputedStyle(fg).color];
wcagRatio(...pair);                          // computed here, live

/* the adjacent tool the platform now also gives you: */
el.style.color = "contrast-color(oklch(45% 0.13 250))";  // black or white only
