The requirement on the wire

When an embedder puts connectionallowlist on an <iframe>, the browser is supposed to send the requirement to the framed server as Sec-Required-Connection-Allowlist. The frame below is a live route on this showcase's own server that echoes back exactly which value — if any — arrived with its navigation. No simulation: what you read in the frame is what the request really carried.

Embedded enforcement is an origin trial in Chrome 157 (no shipped milestone yet). To run the enforcing path today: flip chrome://flags/#enable-experimental-web-platform-features and relaunch, or launch with --enable-blink-features=ConnectionAllowlistEmbeddedEnforcement, or register the origin for the ConnectionAllowlistEmbeddedEnforcement origin trial. On any other build the attribute is inert and the echo below will truthfully show the header as absent.

const frame = document.getElementById("echo-frame");
frame.setAttribute("connectionallowlist",
                   '(response-origin "https://api.example")');
frame.src = "../echo-required";   // navigation now carries (on OT builds):
// Sec-Required-Connection-Allowlist: (response-origin "https://api.example")
