Allowlist builder

The grammar is a structured-header list of one inner list: serialized URLPattern strings and the response-origin token, with report-to, redirects and webrtc parameters. Build one below — the page emits the exact header line, the <iframe connectionallowlist> markup and the Allow-Connection-Allowlist-From opt-in, validates it against the spec's attribute rules, exercises your patterns against real URLs with the real URLPattern engine, and runs the §4.3 satisfies comparison.

What is and is not live here: pattern matching uses this browser's genuine URLPattern implementation (probing…), and the emitted headers are exactly what the handshake lab really serves. Enforcement itself needs a build with --enable-experimental-web-platform-features (flag ConnectionAllowlistEmbeddedEnforcement); the satisfies checker is an in-page implementation of spec §4.3, labelled as such — it computes the algorithm, it does not pretend the browser enforced anything.
