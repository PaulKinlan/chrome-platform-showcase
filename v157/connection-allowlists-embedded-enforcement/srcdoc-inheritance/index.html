Local schemes inherit implicitly

A server-backed frame must opt in with a response header — but an about:srcdoc frame has no server and no headers. The spec's answer: local-scheme documents inherit the embedder's policy container, so they are opted in implicitly, requirement included. This page navigates a srcdoc frame under a connectionallowlist requirement and runs real fetch probes inside it, reporting what actually connected.

On a build without the origin trial, the requirement attribute is inert: both probes succeed and the page says the policy was not enforced. On an enforcing build, the srcdoc frame inherits (response-origin) — which re-resolves to this origin inside the frame — so the same-origin probe still succeeds while the cross-origin probe is refused. Flag/OT steps are on the feature overview banner.

why this matters

Widget markup is often inlined into a srcdoc sandbox precisely so the embedder controls it. If local schemes did not inherit the requirement, srcdoc would be a trivial bypass: wrap any code in <iframe srcdoc> and connect anywhere. Inheritance closes that hole, and the same propagation carries the accepted allowlist into the frame's own descendants and dedicated workers. One subtlety worth knowing: an inherited response-origin token is stored unresolved and re-resolves against each inheriting document's own origin — for a srcdoc frame that is the embedder's origin, so same-origin traffic keeps working.

For nested server-backed frames the rule is different and stricter: a descendant's own connectionallowlist attribute is honored only if it is at least as strict as what it inherited — a child cannot loosen what a parent required.

code path

const frame = document.createElement("iframe");
frame.setAttribute("connectionallowlist", "(response-origin)");
frame.srcdoc = `<script>
  fetch("/v157/.../framed/ping")          // same-origin: allowed by response-origin
  fetch("https://chromestatus.com/…")     // cross-origin: refused when enforcing
</script>`;   // no server, no headers — the policy container is inherited
