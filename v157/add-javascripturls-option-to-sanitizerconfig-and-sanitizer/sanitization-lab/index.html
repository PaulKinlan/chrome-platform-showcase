The javascript:-URL sanitization lab

Edit the markup, choose a method and a javascriptURLs policy, and run the real sanitizer. The lab counts how many javascript: navigating attributes survived, shows the serialized result, and — crucially — demonstrates the Chrome 157 decoupling: before, only "which method did you call" decided; now the config decides, for safe and unsafe methods alike.

Safety note: the sanitized result is serialized to text, never mounted as live DOM on this page, so no javascript: URL here is ever clickable. On a pre-157 build the policy radios have no effect (the member is ignored as an unknown dictionary key) and the lab says so next to the result instead of pretending the option worked. Pre-146 builds need --enable-blink-features=SanitizerAPI for the API at all.
