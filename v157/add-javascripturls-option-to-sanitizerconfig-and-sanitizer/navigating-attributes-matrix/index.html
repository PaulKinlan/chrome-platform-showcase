The navigating-attributes matrix

The option is precise: it governs only the spec's built-in navigating URL attributes list — attribute/element pairs that trigger navigation. This page feeds one javascript: fixture per list entry (plus a non-navigating img src counter-example) through setHTMLUnsafe() with javascriptURLs: false and true, and prints exactly which attributes your browser stripped or kept in each mode.

Runs use setHTMLUnsafe() so that element removal (e.g. a safe method dropping iframe entirely) doesn't mask the attribute behavior under test. On a pre-157 build the two columns come out identical — the option is an unknown dictionary member there — and the verdict line says so plainly. Pre-146 builds need --enable-blink-features=SanitizerAPI.

const host = document.createElement("div");
host.setHTMLUnsafe('<a href="javascript:x">go</a>',
                   { sanitizer: { javascriptURLs: false } });
host.querySelector("a").hasAttribute("href");   // false — stripped

host.setHTMLUnsafe('<a href="javascript:x">go</a>',
                   { sanitizer: { javascriptURLs: true } });
host.querySelector("a").hasAttribute("href");   // true — kept

// img src is NOT on the navigating list — untouched in both modes
