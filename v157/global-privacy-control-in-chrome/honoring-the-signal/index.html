What a compliant site does with it

GPC is not decoration — under the CCPA/CPRA and several other state laws it is a valid do-not-sell-or-share request a business must honour. This preferences center is driven by the visitor's real signal (the DOM property, cross-checked against a live server echo of the Sec-GPC header): when the signal is on, the "sale/share" toggle defaults to opted-out and locks, exactly the behaviour the signal obliges.

No GPC surface on this build? The center still works — it treats "no signal" as "no universal request", which is the spec-correct reading (absence of Sec-GPC means no preference was expressed, not consent). Enable the Chrome 157 setting, or launch with --enable-blink-features=GlobalPrivacyControlForce, then reload to watch the default flip.

code path

function gpcSignal() {
  // Absence is "no preference", never consent.
  if (!("globalPrivacyControl" in navigator)) return "unknown";
  return navigator.globalPrivacyControl ? "on" : "off";
}

if (gpcSignal() === "on") {
  prefs.saleShare = false;        // honour the opt-out…
  lock(prefs.saleShareControl);   // …and stop the UI nagging for it back
}
