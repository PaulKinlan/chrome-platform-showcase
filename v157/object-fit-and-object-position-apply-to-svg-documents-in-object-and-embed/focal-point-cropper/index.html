Interactive SVG focal-point cropper

Why load an SVG in <object> instead of <img>? Because <object> keeps the SVG's internal DOM scriptable via contentDocument. In Chrome 157, you can now crop and pan an <object> schematic using CSS object-fit: cover (or none) and object-position: X% Y% while directly querying and highlighting nodes inside its contentDocument.
