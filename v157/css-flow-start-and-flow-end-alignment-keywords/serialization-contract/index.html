Serialization contract

The aliasing cuts both ways: once these keywords ship, either spelling serializes as flow-start/flow-end — including in getComputedStyle. Code that does style.justifyContent === "flex-start" silently stops matching. This page round-trips every spelling through the CSSOM in your browser and runs the audit that finds the comparisons at risk.

the contract, and the fix

el.style.justifyContent = "flex-start";
el.style.justifyContent;
// pre-157:  "flex-start"
// post:     "flow-start"   ← the breaking read

// brittle:
if (getComputedStyle(el).justifyContent === "flex-start") { … }

// robust across the transition:
const v = getComputedStyle(el).justifyContent;
if (v === "flex-start" || v === "flow-start") { … }

// or test behaviour, not strings:
if (CSS.supports("justify-content", "flow-start")) { /* new regime */ }
