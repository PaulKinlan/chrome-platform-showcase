Launch to present

A composition: a presenter app that combines focus-existing launches, File Handling (LaunchParams.files) and the Fullscreen API. Double-click a .slides file in your OS, or pick the Present from slide 3 app shortcut, and the already-open presenter loads the deck and goes fullscreen straight from the consumer — something only possible once the launch carries activation.

Status: on by default in Chrome 160 (kill switch: --disable-features=WebAppLaunchHandlerUserActivation). Needs this concept installed; File Handling launches also need the one-time “open files with this app?” approval and are desktop-only (Android has no web-app file handlers). Without activation the consumer shows a Present button instead of pretending.

the consumer

launchQueue.setConsumer(async (params) => {
  const activated = navigator.userActivation.isActive;     // read before any await
  if (params.files?.length) deck = parse(await (await params.files[0].getFile()).text());
  goTo(Number(new URL(params.targetURL).searchParams.get("slide")) || 1);
  if (activated) {
    await deckEl.requestFullscreen();   // Chrome 160: allowed on focus-existing delivery
  } else {
    showPresentButton();                // a click supplies activation
  }
});
// awaiting getFile() takes milliseconds — well inside the ~5 s activation window
