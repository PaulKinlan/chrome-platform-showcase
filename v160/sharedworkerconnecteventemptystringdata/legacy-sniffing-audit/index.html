Legacy sniffing audit

A null to "" change sounds harmless, but JavaScript treats the two very differently: JSON.parse(null) returns null while JSON.parse("") throws, d ?? x keeps "" but replaces null, and typeof flips from "object" to "string". Worker code that sniffed e.data to tell a connect from a message, or parsed it blindly, changes behaviour in Chrome 160. This audit runs ten common patterns inside a real shared worker against the real connect event, then runs the same function with the other value so you can see exactly what changes.

the migration-safe pattern

// Before: sniffing data (breaks in Chrome 160)
onconnect = onmessage = (e) => {
  if (e.data === null) return setUp(e.ports[0]);
  handle(e.data);
};

// After: branch on the event type, never on data
self.addEventListener("connect", (e) => setUp(e.ports[0]));
function setUp(port) { port.onmessage = (m) => handle(m.data); }
