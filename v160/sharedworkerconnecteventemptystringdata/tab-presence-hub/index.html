Tab presence hub

The everyday job of a shared worker: one instance coordinating every open tab of an app (presence, a single WebSocket, a shared cache). Each tab that joins produces one connect event in the hub. This page, the frames below and any real tabs you open all connect to the same worker (name: "presence-hub"); the hub keeps a roster and logs the data of every connect event it receives.

why it matters here

Hubs like this often share one handler between the worker scope and its ports, or forward "the first event" into an app-level message bus. Every connect now delivers "" consistently across Chrome, Firefox and Safari, so a hub that forwards connect events (rather than branching on e.type) sees the same value everywhere. The log above shows the value per connect, so you can confirm it is uniform across frames and tabs.
