behaviour differences to know

  • The legacy call threw SyntaxError for a non-audio track or a track with no sender. The find() form throws TypeError when no sender matches (reading .dtmf of undefined) and returns null for a video sender; the optional-chaining style returns null for both, so check the result.
  • If you kept the RTCRtpSender from addTrack(), skip the search: sender.dtmf.
  • Check dtmf.canInsertDTMF before sending; it stays false until negotiation completes.
