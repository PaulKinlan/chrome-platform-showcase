const dtmf = pc.createDTMFSender(track);

After (standard webrtc-pc)

const sender = pc.getSenders()
  .find((s) => s.track === track);
const dtmf = sender.dtmf; // or keep the sender from addTrack()

dtmf.insertDTMF("*12#", 100, 70);

migration notes

    
    
      
  • The legacy method never created anything new in Chromium: it searched pc's senders for the track and returned sender.dtmf. Holding on to the RTCRtpSender from addTrack() / addTransceiver() is the cleanest migration.
    • 
      
  • Feature-detect the replacement with "dtmf" in RTCRtpSender.prototype; never with createDTMFSender.
    • 
      
  • If the track is swapped with replaceTrack(), a s.track === track lookup stops matching. Keep the sender reference instead of re-finding it.
