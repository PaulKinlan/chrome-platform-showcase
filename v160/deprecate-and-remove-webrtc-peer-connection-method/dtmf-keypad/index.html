DTMF keypad

The reason any app called createDTMFSender(): a web softphone that has to "press 1 for sales" on a phone-network menu (IVR) or enter a conference PIN. The standard way is RTCRtpSender.dtmf, which works in every engine. This keypad starts a real call and sends each key with sender.dtmf.insertDTMF() as RFC 4733 telephone-events. The log shows every tonechange event the browser fires.

const sender = pc.addTrack(micTrack, stream);
// ...after negotiation, when sender.dtmf.canInsertDTMF is true:
sender.dtmf.ontonechange = (e) => console.log(e.tone || "done");
sender.dtmf.insertDTMF("1,234#", 100, 70);
