Removal probe

The method being removed is RTCPeerConnection.prototype.createDTMFSender(track), a pre-standard way to get a DTMF (telephone keypad tone) sender. Only Blink ever shipped it. This page checks whether it is still on the prototype, and if it is, calls it on a real call to show what it returns: the very same RTCDTMFSender object the standard sender.dtmf attribute gives you.

pc.createDTMFSender(track);

pc.getSenders().find((s) => s.track === track).dtmf;
