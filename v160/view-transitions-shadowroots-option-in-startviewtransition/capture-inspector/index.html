the participation rule

// Chromium (view_transition_style_tracker.cc), paraphrased:
participatingRoots = { scope.getRootNode(), ...options.shadowRoots };

captured(el) =
     flatTreeDescendant(scope, el)                  // inside the scope element
  && participatingRoots.has(treeScopeOf(nameDecl)); // the stylesheet that named it

// view-transition-class / view-transition-group use the same tree-scope test,
// so a class from a listed root matches ::view-transition-group(*.slow).
  • Closed roots: host.shadowRoot is null for a closed root, so only code that kept the reference from attachShadow() can list it. Here the component registers its own root with the page in a private WeakMap, standing in for “the component opts itself in”.
  • Nested roots: listing the outer component’s root does not pull in the inner component’s root. Tick “nested inner root” to include nested-badge.
  • Out of scope: with the #stage scope, a listed root whose host sits outside #stage contributes nothing.
