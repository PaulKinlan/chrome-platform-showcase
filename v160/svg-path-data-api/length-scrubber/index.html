Route scrubber

The delivery route below is one <path>, and each segment is a leg of the trip. When you move the slider, the page calls path.getPathSegmentAtLength(distance) and path.getPointAtLength(distance) with the same distance. The first returns the leg that covers that distance as a {type, values} dictionary, so the page can name and highlight the current leg without parsing d.

notes

The method returns a copy of the segment, not an index, so this page finds the leg by matching that dictionary against getPathData(). Each leg on this route is unique, so the match is unambiguous. Distance clamps the same way as getPointAtLength(): negative values give the first segment, and values past getTotalLength() give the last. NaN and empty or zero-length paths give null, per the explainer.
