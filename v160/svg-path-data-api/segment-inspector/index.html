what to notice

  • Raw mode keeps the command letters exactly as written. Lower-case letters are relative, and H/V carry a single value.
  • Normalize mode returns only M, L, C and Z. Quadratics become cubics (exact), smooth commands have their reflected control points worked out, and each arc becomes one or more cubics (an approximation).
  • Type an invalid letter into the middle of the path (for example M10 10 L50 50 X20 20 L90 10). The segments before the error are returned and the rest are dropped, the same "render up to the error" rule the renderer follows. The browser also logs a console warning about the malformed d.
  • An empty d gives [], not an exception.
