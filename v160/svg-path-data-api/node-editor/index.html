Node editor

A minimal vector-editor node tool. Anchor points are blue and Bézier control points are rose. Every change makes the same three calls: const segs = path.getPathData(), change one number, then path.setPathData(segs). The d string below is the browser's own serialization after each write. This page has no parser and no serializer.

why this matters

    
Before this API, a node editor in Chromium had to parse d into its own model and serialize it back on every drag, usually with path-data-polyfill. Now the browser is the model. Plain object literals are accepted, because SVGPathSegment is a dictionary, so segs[i].values[j] = x followed by setPathData(segs) is all it takes. Structural edits work the same way: adding or removing a segment is Array.prototype.splice on the result.
