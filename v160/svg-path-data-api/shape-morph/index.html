Shape morph

You can't interpolate between a star made of lines and a circle made of arcs directly. This page uses the browser to put both shapes into one form. getPathData({normalize: true}) reduces each to absolute M/L/C/Z. Lines are then turned into equivalent cubics, and the longest curves are split until both shapes have the same number of segments. Interpolating the numbers and calling setPathData() on every frame produces the morph.

Morph two shapes

how it works

  1. a.getPathData({normalize: true}) and b.getPathData({normalize: true}): the browser handles relative commands, H/V, quadratics, smooth curves and arcs.
  2. Each L becomes a cubic with its control points at 1/3 and 2/3 along the line. A closing Z becomes an explicit closing cubic followed by Z.
  3. The shape with fewer curves has its longest curve split in half (de Casteljau) until both counts match.
  4. Each frame interpolates every value and calls out.setPathData(segments), passing plain objects in.

If you prefer reduced motion, Play jumps to the other end instead of animating. The slider always works.
