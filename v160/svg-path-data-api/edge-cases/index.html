    migration notes

    • SVGPathSegList (path.pathSegList, createSVGPathSegLinetoAbs() and the rest) was removed in Chrome 48 and is not coming back. Firefox removed it in 2018, and only Safari still ships it. The last two cases check this in the current browser.
    • path-data-polyfill installs itself only when SVGPathElement.prototype.getPathData is missing. Because the native methods accept the same {type, values} plain objects, existing polyfill code switches to the native API without changes.
    • A segment that is structurally invalid (missing type or values) throws. A segment that is semantically invalid (unknown letter, wrong number of values) is skipped. Keep this in mind when validating user input: no exception does not mean every segment was accepted.
