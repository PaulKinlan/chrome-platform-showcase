Shared wavetable synth

A three-voice wavetable synth. The voices are separate AudioWorkletProcessors, but they read one wavetable stored in the AudioWorkletGlobalScope. Changing the sound sends one message on audioWorklet.port, and every voice picks the new table up on its next render quantum. Without the shared port, the same update needs one message per voice. why it matters

Shared state such as tuning tables, sample banks, impulse responses or a compiled WebAssembly instance belongs to the global scope, not to any one processor. With AudioWorkletGlobalScope.port, the main thread updates that state once, and processors added later (the next voice, the next note) find it already in place. The per-node fallback also has to track every live node and repeat the send, and a voice created between two sends can miss an update.
