Port inspector

Two IDL attributes, one channel. This tool interrogates both ends: how AudioWorklet.prototype.port is defined, whether it is the same object on every read, whether each BaseAudioContext gets its own, whether it is really readonly — and then asks the module running inside AudioWorkletGlobalScope to describe its port.

what the rows mean

  • Main thread rows read the Window-side IDL: the attribute is a getter on the prototype (no setter, because it is readonly), returns a MessagePort, and “each BaseAudioContext possesses exactly one AudioWorklet”, so two contexts must yield two different ports.
  • Global scope rows are answered by the worklet module over the shared channel itself — so if the channel does not exist, they cannot be answered, and the table says so rather than guessing.
