Readonly, static, and the unknown-value edge

Two attributes, two different homes. reliability is a readonly accessor on WebTransport.prototype — a getter with no setter, so a strict-mode write must throw. supportsReliableOnly is static: it lives on the constructor object and never appears on instances. This page dumps the real property descriptors and runs the writes that prove each claim.

Chrome targets this for Chrome 158 behind WebTransportReliability (--enable-blink-features=WebTransportReliability, or chrome://flags/#enable-experimental-web-platform-features). On a build without the attributes, every panel below reports the missing surface explicitly instead of inventing descriptors.

code path

// Readonly accessor: getter, no setter, on the prototype.
const d = Object.getOwnPropertyDescriptor(WebTransport.prototype, "reliability");
// d → { get: f, set: undefined, enumerable: true, configurable: true }

"use strict";
transport.reliability = "supports-unreliable"; // TypeError — no setter

// Static: on the constructor, never on instances.
Object.getOwnPropertyDescriptor(WebTransport, "supportsReliableOnly"); // accessor
transport.supportsReliableOnly;                 // undefined — statics don't inherit
