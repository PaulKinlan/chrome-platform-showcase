Split request playground

Build a request with the three new window features, split, splitposition and splitsize, and send it with a real window.open(). The opened view measures how the browser presented it and reports back. The browser may honour the hint or decline it, and nothing in the API says which happened (deliberately). What a page can observe is shown verbatim.

what you cannot see, by design

The proposal deliberately omits navigator.splitTabSupported and any "was it split?" result: both would be fingerprinting bits (window size, form factor, settings). It does not have to be a guess, though. The opened view can read toolbar.visible (false only for popups), and if this window shrinks right after the call (a resize event here), a split very likely happened. That resize is the one indirect signal this page records.
