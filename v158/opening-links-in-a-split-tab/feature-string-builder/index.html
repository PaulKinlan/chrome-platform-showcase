what each token does

  • split — boolean, parallel to popup. split=0 / split=no do not request a split (and the legacy popup heuristic then applies).
  • splitposition — left, right, top, bottom. Unsupported or bogus values fall back to the browser default.
  • splitsize — integer percent for the new content. Invalid values are ignored; Chromium clamps to 10–90 so a page cannot request a 1% sliver or hide its opener behind 99%. Try 0 or 100 above: the request is still valid, the clamp happens in the browser.
  • Hints without split request nothing: "splitsize=30" alone is just a non-empty unknown string — a popup.
