Feature-string inspector

The windowFeatures argument is a loosely parsed legacy string, which is why the split proposal has a trap. A browser that does not know split still sees a non-empty string, and the HTML Standard's "check if a popup window is requested" then returns true, so it opens a popup. This tool runs the Standard's tokenizer and popup check in JavaScript, applies the explainer's split rules, and shows both predictions side by side. You can then test the string with a real call.
