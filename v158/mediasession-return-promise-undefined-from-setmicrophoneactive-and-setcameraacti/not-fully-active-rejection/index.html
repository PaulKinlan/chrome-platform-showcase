The one rejection the spec pins down: not fully active

The update capture state algorithm's first step: If document is not fully active, return a promise rejected with InvalidStateError. A document stops being fully active the moment its iframe is removed — so this page creates an iframe, captures its mediaSession, removes the iframe, and then calls setMicrophoneActive(true) on the orphaned session. On 158+ that must produce the rejected promise; on a pre-158 build there is no promise at all. Both real outcomes are shown, labelled.

Ships in Chrome 158, no runtime flag. Everything below runs in this page against a same-origin helper iframe; nothing captures audio or video. The spec also lets a user agent reject with InvalidStateError when active=true and the document is hidden, and with NotAllowedError under a pause policy the user agent refuses to change — neither is deterministic enough to demo, so this page sticks to the mandatory first step.

Run the detach sequence

  1. Append a same-origin <iframe> and wait for it to load.
  2. Capture iframe.contentWindow.navigator.mediaSession and bind setMicrophoneActive.
  3. Remove the iframe — its document is no longer fully active.
  4. Call setMicrophoneActive(true) on the captured session and record what actually happens.

code path

const iframe = document.createElement("iframe");
iframe.src = "about:blank";
document.body.append(iframe);
await new Promise((r) => iframe.addEventListener("load", r, { once: true }));

const session = iframe.contentWindow.navigator.mediaSession;
const setMic = session.setMicrophoneActive.bind(session);

iframe.remove();                      // document: no longer fully active

try {
  const ret = setMic(true);
  // The promise comes from the IFRAME's realm, so `ret instanceof Promise`
  // is false there even on a conforming build — test the thenable shape:
  if (ret && typeof ret.then === "function") {
    await ret;                        // 158+: must reject…
  }
} catch (err) {
  console.log(err.name);              // …with "InvalidStateError"
}
