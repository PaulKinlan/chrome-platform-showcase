Migration: chaining code that survives both shapes

A method whose documented return shape changes between browser revisions is a return-shape drift hazard — a confirmed regression class in this showcase. Code written for Chrome 158's Promise<undefined> crashes with a TypeError on the undefined that Chrome 93–157 returns. This page runs three strategies against the live API and shows exactly which ones survive on the build you are using right now.

Ships in Chrome 158, no runtime flag (a WebIDL return-type alignment). Every strategy below executes the real navigator.mediaSession.setMicrophoneActive(false) — a safe no-op declaration when nothing is capturing. The naive strategy is expected to throw on a pre-158 build; the throw is caught, displayed, and is the lesson.

Run all three strategies

1 · Naive: trust the new spec

navigator.mediaSession.setMicrophoneActive(false)
  .then(() => console.log("acknowledged"));   // TypeError on pre-158!

not run yet

2 · Normalise: Promise.resolve() wraps both shapes

await Promise.resolve(
  navigator.mediaSession.setMicrophoneActive(false),
);  // undefined and Promise<undefined> both land here safely

not run yet

3 · Inspect: branch on the thenable shape

const ret = navigator.mediaSession.setMicrophoneActive(false);
if (typeof ret?.then === "function") {
  await ret;            // 158+: real acknowledgement
} else {
  /* 93–157: fire-and-forget — no signal to wait for */
}

not run yet

why this matters here

This showcase's validation rubric has a mandatory anti-regression case named return-shape drift: "code unconditionally chains .then()/.catch() or iterates an API result whose documented return shape differs across browser revisions." It exists because demos shipped that chained on values that were sometimes not promises. setMicrophoneActive() / setCameraActive() are a textbook instance — the same line of code is correct on Chrome 158 and a crash on Chrome 157. Strategy 2 is the smallest safe form; strategy 3 is the explicit form when the two branches genuinely need different behaviour.
