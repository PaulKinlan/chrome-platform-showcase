Serve your own subtype

The matrix page picks the types; here you do. Whatever you enter is genuinely served by this site's server as the response's Content-Type, then classified by this browser — including the server's real 400 when the string is not a valid MIME token.

Spec-compliant classification ships in Chrome 158. Earlier builds: --enable-blink-features=SpecCompliantXmlMimeTypes or chrome://flags/#enable-experimental-web-platform-features. On a pre-158 build a text/*+xml answer is its raw type (and an unsupported image/*+xml is an empty string) rather than application/xml.
