Probe surface triptych

The platform has three front doors for "can you play this?", and they are allowed to disagree. IAMF ships via MSE, so MediaSource.isTypeSupported() is the authoritative door — this tool asks all three with the same string and shows each surface's literal, unedited return value.

canPlayType() answers about progressive playback (<audio src>) with a vocabulary of '' / 'maybe' / 'probably'; isTypeSupported() answers about MSE with a boolean; decodingInfo() answers a full configuration with supported / smooth / powerEfficient and takes the query type (media-source vs file) as input. A build that decodes IAMF only through MSE may legitimately say yes at the MSE doors and no at the progressive ones.

Pick a preset (or type a content type) and ask. Every readout is the raw return value.

code path

const t = 'audio/mp4; codecs="iamf.000.000.Opus"';

// Door 1 — progressive playback vocabulary: '' | 'maybe' | 'probably'
document.createElement('audio').canPlayType(t);

// Door 2 — MSE, the surface IAMF actually ships on: boolean
MediaSource.isTypeSupported(t);

// Door 3 — full configuration answer, per query type
await navigator.mediaCapabilities.decodingInfo({
  type: 'media-source',   // and again with type: 'file'
  audio: { contentType: t, channels: '2', bitrate: 128000, samplerate: 48000 },
});
