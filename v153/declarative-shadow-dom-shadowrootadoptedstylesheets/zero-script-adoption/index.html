Zero-Script Adoption

The card below is styled by <template shadowrootmode="open" shadowrootadoptedstylesheets="./card.css"> and nothing else — no script touches it. The probe reads the real shadowRoot.adoptedStyleSheets state and reports honestly when the attribute is ignored.

Availability: enabled by default from Chrome 153. On Chrome 148–152 enable chrome://flags/#enable-experimental-web-platform-features, or launch with --enable-blink-features=ShadowRootAdoptedStyleSheet (attribute only) or --enable-blink-features=DeclarativeCSSModules (attribute + inline <style type="module">), or use a DeclarativeCSSModules origin trial token. No dedicated chrome://flags entry exists. Older browsers parse the shadow root but ignore the attribute — the card renders unstyled, which is exactly what the probe detects.

specifier grammar

The attribute value is parsed as an ordered set of unique tokens; each token is resolved and fetched exactly like import spec with { type: "css" }:

  • ./card.css, ../shared.css, /styles/site.css — URL-style specifiers, resolved against the document base URL.
  • showcase-theme — a bare specifier; only valid with an import map entry.
  • The response must be text/css; the sheet's CSSStyleSheet lands in adoptedStyleSheets in attribute order, and a failed fetch leaves an empty sheet in place instead of shifting the order.
