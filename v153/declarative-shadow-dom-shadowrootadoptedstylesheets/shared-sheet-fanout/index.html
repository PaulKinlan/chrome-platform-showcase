v153 · shadowrootadoptedstylesheets

Shared-Sheet Fan-Out

Every chip below names the same specifier, ./badge.css. The spec routes all of them through one module-map entry, so N components adopt one CSSStyleSheet object — parse once, share everywhere, and a single insertRule() restyles the whole fleet.

Availability: Chrome 153+ by default; Chrome 148–152 via chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=ShadowRootAdoptedStyleSheet, or the DeclarativeCSSModules origin trial. Unsupported browsers render the chips unstyled; the clearly labelled script fallback below adopts the same module imperatively — the exact boilerplate this attribute deletes.

why one object matters

<!-- N times, same specifier — the UA parses ./badge.css once -->
<share-chip>
  <template shadowrootmode="open" shadowrootadoptedstylesheets="./badge.css">
    <span class="chip">chip #1</span>
  </template>
</share-chip>

// later, restyle the entire fleet with one call:
const sheet = anyChip.shadowRoot.adoptedStyleSheets[0];
sheet.insertRule('.chip { background: var(--text-black); color: var(--bg-ivory); }');

Compare the alternatives the explainer calls out: duplicated <style> blocks are parsed N times and drift apart; per-root <link> tags re-match N times and can flash. One shared constructable sheet is parsed once, and consistency is structural — there is nothing to keep in sync.
