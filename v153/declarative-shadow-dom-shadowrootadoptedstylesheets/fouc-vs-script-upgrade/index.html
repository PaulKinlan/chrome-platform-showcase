FOUC vs Script Upgrade

The SSR/streaming payoff: the same server-rendered component, replayed side by side. Left adopts ./flash.css declaratively at parse time; right waits for script to import the module and assign adoptedStyleSheets — the gap you can see is the flash of unstyled content.

Availability: Chrome 153+ by default; Chrome 148–152 via chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=ShadowRootAdoptedStyleSheet, or the DeclarativeCSSModules origin trial. Where unsupported, the left lane honestly reports that it never styled (the attribute was ignored) — only the script lane works, which is precisely the pre-153 situation.

avoiding the late fetch

Parse-time adoption removes the script gap, but the module fetch itself can still arrive late on slow networks. ChromeStatus's guidance: preload the referenced sheets in <head>. And note the general-purpose tool this replaces — experiments and theme scripts previously needed blocking="render" tricks to paint styled; a declaratively adopted sheet needs neither script nor render-blocking hacks.

<head>
  <link rel="modulepreload" href="/styles/card.css" as="style">
</head>
<body>
  <template shadowrootmode="open" shadowrootadoptedstylesheets="/styles/card.css">…</template>
