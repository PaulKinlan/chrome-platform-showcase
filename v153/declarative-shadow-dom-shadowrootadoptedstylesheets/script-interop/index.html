v153 · shadowrootadoptedstylesheets

Script Interop

Declarative adoption is not a separate system: the attribute populates the same mutable adoptedStyleSheets ObservableArray script has always owned, and its specifiers live in the same module map as import(). Mutate the array, reverse the cascade order, and prove identity with a dynamic import of the same specifier.

Availability: Chrome 153+ by default; Chrome 148–152 via chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=ShadowRootAdoptedStyleSheet, or the DeclarativeCSSModules origin trial. CSS module import() itself is long-shipped, so on older browsers the labelled imperative fallback still works — only the parse-time half is missing.
