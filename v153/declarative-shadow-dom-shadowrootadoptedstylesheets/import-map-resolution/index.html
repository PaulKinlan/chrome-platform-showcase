v153 · shadowrootadoptedstylesheets

Import-Map Resolution

Specifiers in shadowrootadoptedstylesheets resolve exactly like JavaScript imports — same module map, same import-map rules. So the bare specifier showcase-theme works here only because this page's <script type="importmap"> maps it to ./theme.css, and an unmapped bare specifier fails the same way an unmapped JS import would.

Availability: Chrome 153+ by default; Chrome 148–152 via chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=ShadowRootAdoptedStyleSheet, or the DeclarativeCSSModules origin trial. Import maps themselves are long-shipped, so the JS-side resolution comparison below runs even where the attribute is ignored.

Mapped bare specifier

<script type="importmap">{ "imports": { "showcase-theme": "./theme.css" } }</script>

<template shadowrootmode="open" shadowrootadoptedstylesheets="showcase-theme">
(unmapped-specifier test component appears here)
Idle. "Probe resolution" compares the declarative adoption against a dynamic import of the same bare specifier.
Declarative side unsupported here: the attribute was ignored, so nothing was adopted — but the probe still ran import("showcase-theme", { with: { type: "css" } }) to show that the resolution machinery this attribute reuses already works in your browser. Real parse-time adoption needs Chrome 153+, or 148–152 with chrome://flags/#enable-experimental-web-platform-features / --enable-blink-features=ShadowRootAdoptedStyleSheet, or the DeclarativeCSSModules origin trial.

why this matters

Design systems can publish one import map ("ds/tokens", "ds/card" …) and every server-rendered component adopts by name, not by path — the same indirection JS dependencies get. Swap the mapping and every component re-themes at the next navigation without touching any markup. An unmapped bare specifier is a resolution error: expect a console error from the UA and no adopted sheet for that token (per spec a fetch failure after successful resolution instead leaves an empty placeholder sheet, keeping attribute order stable).
