Worklet quantum meter

The measurement no engine can fake: an AudioWorkletProcessor counts the frames in every process() input block while an OfflineAudioContext — constructed with your chosen renderSizeHint — renders half a second of silence. Whatever number comes back is the render quantum the engine really used.

Pick a hint and render — the worklet reports from inside the audio engine.
// meter-processor.js (inline via Blob URL on this page)
class MeterProcessor extends AudioWorkletProcessor {
  process(inputs, outputs) {
    this.port.postMessage(outputs[0][0].length);   // the REAL block size
    return false;                                  // measure once, then stop
  }
}
registerProcessor("meter", MeterProcessor);

const ctx = new OfflineAudioContext({
  numberOfChannels: 1, length: 24000, sampleRate: 48000,
  renderSizeHint: 256,
});
await ctx.audioWorklet.addModule(moduleUrl);
new AudioWorkletNode(ctx, "meter").connect(ctx.destination);
await ctx.startRendering();   // port message: 128 today · 256 on Chrome 153
