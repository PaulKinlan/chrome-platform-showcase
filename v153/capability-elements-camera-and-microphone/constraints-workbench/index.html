Constraints workbench

Each element takes exactly one MediaTrackConstraintSet via setConstraints() — set it before the user clicks, and the element folds it into the getUserMedia() call it runs on your behalf. Build a real constraint set below: every key is checked live against this browser's actual getSupportedConstraints() vocabulary, the exact call is rendered as you edit, and — where the elements exist — applied to live <camera>/<microphone> elements for real.

The filtering rule: the User Agent deliberately ignores advanced constraint lists and required/exact semantics here. A plain getUserMedia({video: {width: {exact: 99999}}}) can reject with OverconstrainedError; a capability element must never silently die on a click, so its constraints are treated as preferences only. (Source: Media Capture Elements explainer, "Constraint Filtering".)
