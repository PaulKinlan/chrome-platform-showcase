Element surface probe

The single-capability elements ship as real DOM interfaces: HTMLCameraElement and HTMLMicrophoneElement, each mixing in the capture base (error, onerror, oncancel) and the track surface (track, ontrack, setConstraints()). This page probes every one of those members on this browser — and demonstrates the tag-sniffing trap: an unsupported <camera> parses as HTMLUnknownElement, so only an instanceof check against the real interface proves support.

Not seeing support? The elements are listed for Chrome 153 behind the CameraAndMicrophoneElements runtime feature (marked stable in current Chromium source — default-on in new builds). On builds where the probe fails, relaunch with --enable-blink-features=CameraAndMicrophoneElements or enable chrome://flags/#enable-experimental-web-platform-features. The comparison rows for <usermedia> need UserMediaElement too.

// Naive sniff — WRONG: unknown tags still "create" an element
const el = document.createElement("camera");     // HTMLUnknownElement when unsupported

// Real detection: the interface must exist AND claim the element
const supported = typeof HTMLCameraElement !== "undefined" &&
                  el instanceof HTMLCameraElement;
