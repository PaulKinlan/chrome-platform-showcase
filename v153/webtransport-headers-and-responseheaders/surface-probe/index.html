Surface probe

Only one half of this feature is honestly detectable: the readable responseHeaders attribute on the prototype. The request-side headers option lives in a dictionary — and WebIDL silently ignores unknown dictionary members, so "the constructor accepted my headers" proves nothing. The probe demonstrates both facts with real calls.
