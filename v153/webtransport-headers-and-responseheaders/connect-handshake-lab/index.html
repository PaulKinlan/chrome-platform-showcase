CONNECT handshake lab

Compose the request headers, pick an HTTP/3 WebTransport endpoint, connect for real. On establishment the lab reads transport.responseHeaders and lists every entry the server sent. Failures are first-class results here — DNS, UDP blocked, no H3, flag off — each surfaced as the browser actually reported it.

responseHeaders is not exposed in this browser — the connection attempt is still real, and if it establishes the read step will honestly report the attribute's absence. Chrome 153+ with --enable-blink-features=WebTransportHeaders completes the loop.

const transport = new WebTransport(url, {
  headers: {
    authorization: "Bearer demo-token-123",   // rides the extended CONNECT
    "x-showcase-meta": "weekly-hardening",
  },
});
await transport.ready;
for (const [name, value] of transport.responseHeaders) {
  console.log(name, value);                   // the server's reply headers
}
