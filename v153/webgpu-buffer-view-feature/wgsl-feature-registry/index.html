WGSL feature registry

WGSL language features have their own detection surface — navigator.gpu.wgslLanguageFeatures, a setlike readable without requesting any adapter or device. Everything below is enumerated live from your browser; the buffer_view card shows this release's feature, present or honestly absent.

Enumerating…
// No adapter needed — language features are a static property of the engine:
const feats = navigator.gpu.wgslLanguageFeatures;
feats.has("buffer_view");        // this release's feature
[...feats];                      // everything your WGSL compiler speaks

// Contrast with DEVICE features (hardware-dependent, need an adapter):
