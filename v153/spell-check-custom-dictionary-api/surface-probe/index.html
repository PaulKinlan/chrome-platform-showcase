enable it, exactly

  1. Launch Chrome 153+ with --enable-blink-features=SpellCheckCustomDictionaryAPI (the exact runtime_enabled_features.json5 name), or
  2. enable chrome://flags/#enable-experimental-web-platform-features and relaunch,
  3. then reload — the attribute probe flips without any editing surface involved.
const dict = document.spellCheckCustomDictionary;   // undefined before 153+flag

dict.addWords(["Igalia", "Wolvic", "spidermonkey"]); // ignored-word semantics:
dict.removeWords(["Wolvic"]);                        // transient, per-document,
                                                     // never the user's dictionary
