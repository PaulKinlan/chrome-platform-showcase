Domain-vocabulary editor

The textarea is spell-checked and full of words your browser's dictionary doesn't know but this "product wiki" considers canonical. Add them to the document dictionary — each chip and the input drive the real addWords()/removeWords() — then click into the textarea: on a supporting engine with spell check on, the squiggles for added words vanish. Whether a squiggle is visible is manual observation — no API reads squiggle state back — but every call and its outcome below is real.

The dictionary surface is not exposed here — the word manager still runs and shows each real call's genuine failure. Chrome 153+ with --enable-blink-features=SpellCheckCustomDictionaryAPI (or chrome://flags/#enable-experimental-web-platform-features) makes the calls real; the squiggles also need browser spell checking enabled.
