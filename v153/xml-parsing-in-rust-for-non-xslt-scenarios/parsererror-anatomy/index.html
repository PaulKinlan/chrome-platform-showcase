parsererror anatomy

XML parse failure never throws — parseFromString returns a document whose root or first child is a <parsererror> element with human-readable details inside. Even its namespace is engine lore: Firefox uses a Mozilla-specific error namespace, WebKit and Chrome put it in the XHTML namespace — so robust detection matches the local name across namespaces. Edit the XML (or use a breakage preset) and inspect the exact error document this engine constructs; the structure is what the Rust parser must reproduce.
