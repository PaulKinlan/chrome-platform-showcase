Streaming into a WritableStream

The stream…HTML family — streamHTML, streamAppendHTML, streamPrependHTML, streamBeforeHTML, streamAfterHTML, streamReplaceWithHTML and their Unsafe twins — return a WritableStream whose chunks feed the real streaming HTML parser, so markup can render progressively and tags may split across chunk boundaries.

Flag required in Chrome 153. Blink runtime feature NewHTMLSettingMethods (experimental; depends on SetHTMLCanRunScripts, StreamingSanitizer, TrustedTypesCreateParserOptions). Enable chrome://flags/#enable-experimental-web-platform-features in Chrome/Canary 153+ and relaunch, or launch with --enable-blink-features=NewHTMLSettingMethods,SetHTMLCanRunScripts,TrustedTypesCreateParserOptions. Without it, the lab below runs a clearly-labelled timing illustration instead — never a fake streaming pass.

code

const writable = container.streamAppendHTMLUnsafe({});
const writer = writable.getWriter();
for (const chunk of chunks) {        // tags may split across chunks —
  await writer.write(chunk);         // the streaming parser buffers them
}
await writer.close();

// or pipe a whole stream:
readableOfMarkup.pipeTo(container.streamHTMLUnsafe({}));
