Child document: opt-in restricted to another origin

This document carries <meta name="responsive-embedded-sizing" allowedorigins="https://example.com">. In Chromium's implementation the allowedorigins list (CSP frame-ancestors syntax) is matched against the embedding page's origin — which is not example.com here, so size exposure is refused and the frame stays at 150px.
