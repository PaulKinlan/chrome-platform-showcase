Responsively-sized <iframe>

For twenty years an <iframe> has been a fixed 300×150 box that scrolls internally, and every embed provider has shipped a postMessage resize script to work around it. This feature lets an iframe finally size itself to its content — via a double opt-in: the embedding page sets the new frame-sizing CSS property on the <iframe> element, and the embedded document opts in with a <meta name="responsive-embedded-sizing"> tag in its <head>. The browser then treats the child document's laid-out size as the iframe's natural (intrinsic) size, exactly like an image's natural dimensions — no script, no scrollbars.

why it shipped

Sites embed third-party widgets (comments, payment forms, worked examples in teaching material) in iframes for style, layout and security isolation — but an iframe cannot size to its content, so every provider ships a custom postMessage height-reporting script, and users get nested scrollbars when it breaks. Demand goes back to whatwg/html#555 (2016) and csswg-drafts#1771. The double opt-in (embedder CSS + embedded meta) keeps backward compatibility and preserves cross-origin privacy: a document's size is only exposed to embedders it explicitly allows. Sizing is one-shot at load (plus explicit requestResize() calls) to prevent layout loops and reduce layout shift.

enablement

Scheduled for Chrome 153 (desktop, Android, WebView; ChromeStatus lists the entry as “Enabled by default” category, status Proposed as of 2026-07-26). In current builds the Blink runtime flag is ResponsiveIframes (status: experimental). To try it before 153: enable chrome://flags/#responsive-iframes and relaunch, or launch with --enable-features=ResponsiveIframes, or --enable-blink-features=ResponsiveIframes, or --enable-experimental-web-platform-features. Note: the spec draft defines the opt-in meta as <meta name="responsive-embedded-sizing">; Chromium's current implementation additionally requires an allowedorigins attribute on that meta (CSP frame-ancestors syntax, matched against the embedding origin) before the opt-in takes effect. The demos include it.
