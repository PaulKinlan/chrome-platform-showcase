Single-axis scroll containers

overflow: scroll clip finally means what it says. Until now the clip half was silently converted to hidden, so every scroll container was scrollable on both axes as far as position: sticky and script APIs were concerned. With this change an axis set to clip is truly not a scroll axis: sticky is constrained per axis by the nearest ancestor that actually scrolls that axis, and scrollBy()/scrollIntoView() can no longer move a clipped axis away from 0.

concepts

  1. Computed-value probe

    The one-line truth test: an element declared overflow: scroll clip either computes to scroll clip (this feature) or gets legacy-converted to scroll hidden. The probe reads the real computed style and then genuinely tries to script-scroll the clipped axis — both results are live, on any engine.

  2. Sticky per-axis stage

    The explainer's flagship: a data table that scrolls horizontally inside a vertically-scrolling page, with sticky column labels. Scroll both ways and watch the measured positions — with true clip, the sticky top row answers to the page's vertical scroll instead of being trapped by the table.

  3. clip vs hidden for script APIs

    Two identical carousels, one scroll hidden, one scroll clip. The same scrollIntoView() call script-scrolls the hidden one into a state the user can't fix — and must leave the clip one pinned at 0. Real measurements after each call show which engine behavior you're seeing.

why it shipped

A table that pans horizontally inside a page that scrolls vertically is one of the most common layouts on the web, and it has never had a correct spelling: overflow: scroll hidden leaves the vertical axis scriptable (so scrollIntoView can wedge content out of view with no user recovery) and makes position: sticky treat the element as a two-axis scroller. Script emulations with scroll events drain battery and lag by design (scrolling is async). Making clip a first-class partner to scrollable values fixes both with one declaration — at a known small compat risk (the old silent conversion is gone), tracked by the SingleAxisScroller use counter.
