Sticky per-axis stage

The explainer's Example 1, live: this table pans horizontally inside its overflow: scroll clip wrapper while the page owns vertical scrolling. Row labels (sticky left) stick against the wrapper's horizontal scroll; the header row (sticky top) should answer to the page's vertical scroll — because under true clip the wrapper simply isn't a vertical scroll container. Pan the table, scroll the page, and read the measurements.

.pannable-table-wrapper {
  overflow: scroll clip;   /* x: user-scrollable · y: truly not a scroll axis */
}
.pannable-table-wrapper thead th { position: sticky; top: 0; }
.pannable-table-wrapper tbody th { position: sticky; left: 0; }
/* With true clip, `top: 0` resolves against the nearest ancestor that
   scrolls vertically — the page — so headers survive page scrolling.
   Under the legacy hidden-conversion the wrapper itself traps them. */
