clip vs hidden for script APIs

Two identical carousels, taller than their boxes. Both hide the vertical overflow from the user — but hidden still lets script scroll it, while true clip pins the axis at 0. The button calls the same scrollIntoView() on the highlighted item in both; the readouts measure each carousel's real scrollTop afterwards.
