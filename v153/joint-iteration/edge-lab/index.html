why strings are rejected

Strings are iterable, so Iterator.zip("abc") could have zipped "a", "b", "c" — and Iterator.zip(["abc", [1, 2]]) could have iterated characters. Both throw TypeError instead: the proposal uses GetIteratorFlattenable(…, reject-primitives), the same conservative choice as flatMap, because implicitly exploding a string into characters is almost always a bug. Wrap intentionally: Iterator.zip([[..."abc"], [1, 2]]).

Iterator.zip("abc")            // TypeError — outer argument must be an object
Iterator.zip(["abc", [1, 2]])  // TypeError — string ELEMENT rejected too
Iterator.zip([[..."abc"], [1, 2]]).toArray()  // [["a", 1], ["b", 2]] — explicit wins
