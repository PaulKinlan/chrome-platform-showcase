Mode & padding explorer

Fixed, deliberately mismatched inputs — ["a","b","c"] (3) and [1,2,3,4,5] (5) — and one choice: the mode. Every run is the real call; strict genuinely throws, and longest uses a per-source padding array so the short list gets its own filler.

Iterator.zip is not exposed in this engine — each mode still performs the real call and shows its genuine error. Chrome 153+ with chrome://flags/#enable-javascript-harmony stages the proposal.
