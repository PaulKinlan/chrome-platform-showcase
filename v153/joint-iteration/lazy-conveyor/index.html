Lazy conveyor

Both inputs here are infinite generators — naturals and Fibonacci — instrumented to log every pull and their own shutdown. Zipping them can only work if Iterator.zip is pull-based, and stopping early can only be safe if the zip closes its sources: the spec's IteratorCloseAll runs each generator's finally block. Watch both happen.

code path

function* naturals() { let n = 1; try { while (true) yield n++; }
                       finally { log('naturals closed'); } }
function* fibs()     { let [a, b] = [1, 1]; try { while (true) { yield a; [a, b] = [b, a + b]; } }
                       finally { log('fibs closed'); } }

// pull-based: only n pairs are ever computed from the infinite sources
Iterator.zip([naturals(), fibs()]).take(n).toArray();

for (const [n, f] of Iterator.zip([naturals(), fibs()])) {
  if (n >= 3) break;   // break → return() → IteratorCloseAll → both finally blocks run
}
