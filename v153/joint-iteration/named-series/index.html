Named series

Columnar data arrives as separate arrays — timestamps in one, temperatures in another, humidity in a third. Iterator.zipKeyed() turns them into named rows in one call. This page merges three real series into a rendered table, then inspects the detail the spec hides in plain sight: every yielded row is a null-prototype object.

code path

const rows = Iterator.zipKeyed({
  time:     ['09:00', '09:05', …],
  temp:     [16.2, 16.4, …],
  humidity: [61, 63, …],
}).toArray();

rows[0]                              // { time: '09:00', temp: 16.2, humidity: 61 }
Object.getPrototypeOf(rows[0])       // null — spec: OrdinaryObjectCreate(null)
rows[0].hasOwnProperty               // undefined! use Object.hasOwn(row, 'temp')
