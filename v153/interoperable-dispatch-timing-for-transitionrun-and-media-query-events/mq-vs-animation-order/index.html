MQ-vs-animation order

The iframe below carries a (max-width: 300px) media query listener and a transitioning box. The button shrinks the iframe and pokes the transition in the same task, so both a change event and transition events become pending in one rendering update. The inner document timestamps every event and posts the true arrival order out — step 3.10 (media query) must come before step 3.11 (animation events).
