Creation-context comparison

The fix's precise wording matters: events fire at step 3.11 "even for animations created earlier in the same iteration". This lab creates one transition from a plain task (early in the iteration, before rendering) and one from inside a requestAnimationFrame callback (inside the rendering update itself) — and measures rAF-ticks-until-transitionrun for each. Spec-aligned engines report 0 for both.
