transitionrun latency lab

The run button flips the square's class inside a plain task, then counts requestAnimationFrame ticks until the real transitionrun event lands. Spec-aligned engines deliver it during the same rendering update — before the first subsequent rAF callback fires, so the counter reads 0. Old Blink deferred it an iteration: the counter reads 1 (or more).
