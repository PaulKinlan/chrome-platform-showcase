Variable width stage

The width descriptor family exists to talk to real width axes. This stage loads a variable font with a genuine wdth axis (50–200), registers it through the FontFace constructor using the new width descriptor with the legacy stretch descriptor alongside, and lets a slider drive the axis through the high-level property — font-width where this browser supports it, the font-stretch legacy alias otherwise. Advance widths are measured live so you can verify the axis really moved.

About the font: system fonts can’t be trusted to carry a wdth axis, so this page ships its own — a deliberately blocky 5×7 pixel-style variable font (15 KB, built with fontTools for this demo, A–Z + digits). Its charm is debatable; its axis is real.

the code

// Register the face: new descriptor name + legacy alias, same attribute.
// Pre-153 ignores `width` and honours `stretch`; 153+ treats them as one.
const face = new FontFace("ShowcaseWidthVF", "url(data:font/ttf;base64,…)", {
  width: "50% 200%",
  stretch: "50% 200%",
});
await face.load();
document.fonts.add(face);

// Drive the axis with the high-level property (preferred over raw tags):
el.style.setProperty("font-width", pct + "%");     // Chrome 153+
el.style.setProperty("font-stretch", pct + "%");   // legacy alias, works everywhere
