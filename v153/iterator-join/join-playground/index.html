Type comma-separated values and a separator; the run button builds a real generator over your values and calls the native .join() on it. The result panel shows exactly what the engine returned — or the exact error when the method isn't there.

Iterator.prototype.join is not exposed in this engine — the run button still performs the real call so you can see the genuine TypeError. To get the native method: Chrome 153+ with chrome://flags/#enable-javascript-harmony or --enable-experimental-web-platform-features.
