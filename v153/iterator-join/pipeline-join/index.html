Pipeline join

The motivating use case from the proposal: a helper pipeline that ends in a string. Paste a messy tag list, and a real .values().map().filter() chain trims it, drops empties, de-duplicates — then .join(separator) concatenates the survivors in one streaming step, no intermediate array.
