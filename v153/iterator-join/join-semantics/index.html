Join semantics

The contract is deliberately Array.prototype.join's, transplanted: an undefined separator means a comma, any other separator goes through ToString (objects included), null and undefined elements contribute empty strings, the iterator is consumed exactly once, and a non-object receiver is a TypeError. Every row below is a real call.
