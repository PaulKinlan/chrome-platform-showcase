No array detour

Before join landed on iterators there were two workarounds, and both have a cost: Array.from(it).join() materialises the whole sequence, and bare reduce allocates every intermediate string and throws on an empty iterator. All three run here against the same source — including the empty case, where the old reduce pattern genuinely blows up in every current browser.
