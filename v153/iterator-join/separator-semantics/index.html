Separator semantics lab

The separator argument has real coercion rules: undefined becomes ",", numbers and objects go through ToString, and Symbols throw. Elements have their own rule — undefined and null render as the empty string but keep their separators, exactly like Array.prototype.join. Pick a dataset, run the whole separator matrix against it, and read what actually came back.

the rules, straight from the spec

4. If separator is undefined, let sep be ",".
   Else, let sep be ? ToString(separator).       // numbers, objects: coerced
                                                 // Symbols: TypeError
…
8.d. If value is neither undefined nor null,      // holes render as ""
       set result to result + ? ToString(value)  // but still get separators

So [1, undefined, null, 2].values().join("|") is "1|||2" — three separators, two invisible elements — and [1, 2].values().join(0) is "102" because the number 0 coerces to the string "0". Both results in the matrix above come from the running engine, not from copy.
