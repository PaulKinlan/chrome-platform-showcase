The proposal's whole contract fits in one sentence: same semantics as Array.prototype.join. This table takes the historically tricky cases and runs both sides live — the array method on an array, the iterator method on a generator over the same values — and compares the strings character-for-character.

// The rules inherited from Array.prototype.join:
[undefined, null].join("-")      // → "-"      (both stringify to "")
[].join("×")                     // → ""       (empty input, empty string)
["a"].join("×")                  // → "a"      (no separator used)
[1, 2, 3].join()                 // → "1,2,3"  (default separator ",")
[[1, 2], "x"].join(";")          // → "1,2;x"  (elements via ToString)
