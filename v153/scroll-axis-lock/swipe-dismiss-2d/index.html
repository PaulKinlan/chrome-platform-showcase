2D swipe-dismiss

The photo card sits at the center of a 2× scroll space with scroll-axis-lock: none. Swipe it away mostly upward with a natural sideways drift — the card fades with your vertical progress while your horizontal drift stays live instead of being snapped to a rail. All numbers below come from the real scroll offsets; the fade is driven by them, not by pointer math.

scroll-axis-lock is unknown to this engine — the stage still works, but a gesture that starts vertically will be locked to the vertical rail (drift ≈ 0). That IS the pre-153 behavior this feature removes; on Chrome 153 the drift number follows your finger.

dismiss progress: 0% · horizontal drift: 0px

.dismiss-stage {
  overflow: auto;
  scroll-axis-lock: none;   /* the drift stays under the user's control */
}
stage.addEventListener("scroll", () => {
  const progress = Math.abs(stage.scrollTop - centerY) / centerY;
  card.style.opacity = String(1 - progress);   // dismissal follows the gesture
});
