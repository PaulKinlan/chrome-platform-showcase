Dual pan stage

Two identical 1400×900 grids in 2-axis scrollers. Left: default (auto). Right: scroll-axis-lock: none. Start a mostly-vertical touch drag or wheel gesture, then curve it sideways — each trace below plots the real (scrollLeft, scrollTop) path. Locking draws an "L"; freedom draws your curve. Script scrolling is never locked, so the honest way to see the difference is your own gesture.

scroll-axis-lock is unknown to this engine — both stages will show the default locking heuristic (two "L"-shaped traces). That's the genuine pre-153 behavior; on Chrome 153 the right-hand trace follows your diagonal.

scroll-axis-lock: auto

default heuristic — gestures lock to one axis

scroll: 0, 0

scroll-axis-lock: none

gestures keep their true diagonal vector

scroll: 0, 0

.map-viewport {
  overflow: auto;
  scroll-axis-lock: none;   /* diagonal pans stay diagonal */
}
