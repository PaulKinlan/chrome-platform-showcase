Blocked-worker monitor

A live worker echoes a ping every 100ms while a LoAF observer runs inside it. The block button makes the worker spin synchronously for 300ms — real jank in a real worker. Two instruments read the damage: the round-trip meter (spikes on every engine, because queued messages wait) and the worker's own long-animation-frame entries (Chrome 153 — the attribution layer).

// inside the worker:
new PerformanceObserver((list) => {
  for (const e of list.getEntries()) {
    postMessage({ loaf: { duration: e.duration, blocking: e.blockingDuration } });
  }
}).observe({ type: "long-animation-frame", buffered: true });

onmessage = ({ data }) => {
  if (data === "block") {
    const end = performance.now() + 300;      // the jank
    while (performance.now() < end) {}
  }
};
