Worker support probe

Support questions about a worker context must be answered from a worker context — the window's globals prove nothing. The button spawns a real dedicated worker; the worker enumerates its own PerformanceObserver.supportedEntryTypes, attempts a real observe({type: "long-animation-frame"}), and posts both verdicts back.

Runs automatically on load.

// worker.js — the only honest place to ask:
const types = PerformanceObserver.supportedEntryTypes;
let observeResult;
try {
  new PerformanceObserver(() => {}).observe({ type: "long-animation-frame" });
  observeResult = "accepted";
} catch (e) {
  observeResult = e.name;          // TypeError on engines without the extension
}
postMessage({ types, observeResult });
