Stream teardown

An aborted body doesn't reject in just one place. This page aborts one streamed response and captures every teardown surface at once — the pending reader.read(), the reader.closed promise, and a parallel clone().arrayBuffer() — for three different kinds of reason: a rich DOMException, a plain string (abort reasons can be any value), and no reason at all (the spec's default AbortError).

code path

const controller = new AbortController();
const response = await fetch(url, { signal: controller.signal });
const clone = response.clone();          // reads the same body in parallel
const reader = response.body.getReader();
await reader.read();                     // first chunk arrives
const surfaces = {
  read:   reader.read(),                 // now pending mid-stream
  closed: reader.closed,
  clone:  clone.arrayBuffer(),
};
controller.abort(reason);                // reason: DOMException | string | undefined
// Chrome 153+: all three reject with `reason` (default: an "AbortError" DOMException)
// Chromium <153: all three reject with a generic AbortError regardless
