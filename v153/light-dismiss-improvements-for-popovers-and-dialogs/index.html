Light dismiss improvements for popovers and dialogs

Chrome 153 changes what triggers light dismiss: popovers and closedby dialogs now close on a real click outside instead of the old pointerdown+pointerup pair. Two long-standing bugs disappear — touch scrolling no longer dismisses your popover, and right clicks no longer dismiss it. These demos let you perform the exact gestures and watch which event actually closed the surface.

concepts

  1. Dismiss trigger lab

    A real popover and a closedby dialog with a guided gesture matrix: press-and-hold outside, right-click outside, plain click outside — each verdict derived from what your browser actually did.

  2. Scroll survivor

    The headline bug fix: open the popover, then scroll the page by dragging/touch. Old behavior dismisses on the scroll gesture; Chrome 153 keeps it open. Live survived/dismissed verdicts from real toggle events.

  3. Mechanism timeline

    An event-stream inspector logging pointerdown, pointerup, click, contextmenu, and popover toggle with millisecond offsets — so you can see exactly which event coincided with the dismissal in your browser.

why it shipped

Dismissing on pointerdown meant any touch-scroll or right-click that started outside a popover killed it — an interaction bug every popover-based UI inherited. Keying light dismiss off the completed click matches user intent.
