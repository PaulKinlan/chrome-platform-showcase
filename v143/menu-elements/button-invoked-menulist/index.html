Button-invoked menulist

The explainer wires a <button commandfor> to a <menulist>, and gives <menuitem> the command/interest invoker mixins. This page probes that exact wiring surface in your browser — then drives a clearly-labelled fallback so the interaction is demonstrable either way.

Developer trial. Real declarative invocation needs --enable-blink-features=MenuElements on Chrome 143+ (and the command-invoker surface). The probes below report the real state; the fallback path is loudly labelled and never pretends to be native.
