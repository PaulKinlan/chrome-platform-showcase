Keyboard Navigation vs ARIA Pattern

The same application menu twice: once with the new declarative elements (semantics and keyboard model free), and once as the hand-built role="menubar" ARIA pattern every production site ships today. The ARIA version is a real, working menu — usable in this browser right now.

Behind a flag. Runtime feature MenuElements (status experimental; no dedicated chrome://flags entry). In Chrome 143+ enable chrome://flags/#enable-experimental-web-platform-features and relaunch, or launch with --enable-blink-features=MenuElements.
