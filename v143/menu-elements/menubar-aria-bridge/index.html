Menubar ARIA bridge

Left: the pattern developers hand-build today — a WAI-ARIA-practices menubar with roving tabindex, arrow-key navigation, Escape dismissal, and aria-disabled. It fully works in this page. Right: the equivalent declarative markup using the new elements, rendered live so you can see exactly what your browser does with it — with the state reported honestly.

Developer trial. The declarative pane only gains real menu semantics behind --enable-blink-features=MenuElements on Chrome 143+. Without it, the elements render as unknown inline elements — that is the honest unsupported rendering, and this page says which one you are seeing.
