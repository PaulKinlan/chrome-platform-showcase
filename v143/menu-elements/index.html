Menu elements

A new family of HTML elements — <menubar>, <menulist>, <menuitem>, and <submenu> — for building application menus with the correct implicit ARIA roles, checkable state, and keyboard behavior out of the box. <menulist> behaves as a native popover anchored to its invoker, so menus get top-layer rendering, light dismiss, and anchor positioning without JavaScript. Behind a flag: enable chrome://flags/#enable-experimental-web-platform-features or launch with --enable-blink-features=MenuElements (Chrome 143+).

why it shipped

Application menus are ubiquitous but notoriously inconsistent and inaccessible when hand-rolled: the legacy <menu> element is just a styled list with no menu semantics, so every site re-implements ARIA roles, roving focus, and popup positioning differently. The menu elements build on the Popover API, Invoker Commands, and CSS anchor positioning to give developers accessible-by-default menus — implicit menubar/menu/menuitem(radio|checkbox) roles, APG-style keyboard navigation, and checkable state — from markup alone.
