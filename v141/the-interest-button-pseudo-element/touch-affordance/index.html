A hovercard you can reach with a thumb

The classic interest-invoker demo is a mention hovercard: hover or focus a name, get a card. On touch, neither gesture exists and a long-press on a link opens the context menu instead. With one CSS rule, each mention below grows a round tappable chip — the ::interest-button — that fires the same interest action a hover would.

Recent Chrome builds (verified on Chrome 153) ship this enabled; if the chips don't render on yours, enable chrome://flags/#enable-experimental-web-platform-features or launch with --enable-blink-features=HTMLInterestForInterestButtonPseudo. Where only the base invoker ships, hover and keyboard focus still open the cards (try it); where neither ships, the links below are plain links and the readout says so — the demo never fakes a card.

Mentions with hovercards

The interest-invokers proposal was shaped in Open UI, specified in CSS Pseudo-Elements 4, and its touch story settled on the opt-in pseudo-element — see the ChromeStatus entry.
