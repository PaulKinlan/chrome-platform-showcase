Styling playground

::interest-button is fully styleable. It renders nothing until the author sets content, and it inherits from its link or button. Use the controls to build a rule. It is injected into a real stylesheet, the specimen re-renders, and the page measures how wide the generated box is.

Flag: HTMLInterestForInterestButtonPseudo (experimental). Enable chrome://flags/#enable-experimental-web-platform-features, or launch with --enable-blink-features=HTMLInterestForInterestButtonPseudo. Without it the generated CSS below still parses, but nothing renders. The "measured box" readout says so instead of drawing a fake button.

design notes

  • The spec suggests ⓘ (U+24D8) and gating on any-pointer: coarse, because long-press on links is what conflicts with the context menu on touch. Nothing is wrong with showing it more widely.
  • / "" marks the glyph as decorative. The pseudo-element is not in the accessibility tree anyway, so the link's own name and its interestfor hint carry the meaning.
  • The 44px box gives a comfortable finger target. Because the pseudo-element inherits from the link, a bare glyph would otherwise take on the link's small inline line box.
