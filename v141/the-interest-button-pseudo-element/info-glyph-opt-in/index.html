The ⓘ opt-in

The CSS Pseudo 4 example, made live. ::interest-button has no UA content, so nothing appears until an author opts in. Flip the content value and the media-query gate below; the readout measures whether a box was really generated after each host. Then tap or click the ⓘ: interest is shown in the link or button immediately, with no hover delay.

Flag: Blink feature HTMLInterestForInterestButtonPseudo (status experimental). Enable chrome://flags/#enable-experimental-web-platform-features and relaunch, or start Chrome with --enable-blink-features=HTMLInterestForInterestButtonPseudo or --enable-experimental-web-platform-features. No dedicated chrome://flags entry exists.

Generation is checked by geometry: an empty marker <span> sits after each host, and the page compares its x position against the same layout with content: none. A shift means a box exists. CSS.supports("selector(::interest-button)") is shown too but is not trusted: Chrome parses the selector and reports computed content even with the flag off, when no box is drawn.
