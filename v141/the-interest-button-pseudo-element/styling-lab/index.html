Styling is the switch

There is no HTML attribute and no JS call to turn ::interest-button on — authoring styles for it is the opt-in. This lab swaps real stylesheet rules in and out (none, chip, block button, custom content) and reads back getComputedStyle(el, "::interest-button") after each swap, so you can watch the generated box appear, change, and disappear.

Recent Chrome builds (verified on Chrome 153) ship this enabled; if not on yours, use chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=HTMLInterestForInterestButtonPseudo. On builds without the pseudo-element, the presets still swap the stylesheet for real and the computed read-back honestly shows nothing changing.

const sheet = new CSSStyleSheet();
document.adoptedStyleSheets = [sheet];

// opt IN:
sheet.replaceSync(`a[interestfor]::interest-button {
  background: black; color: ivory; padding: 2px 10px; }`);

// opt back OUT — no styles, no button:
sheet.replaceSync("");
