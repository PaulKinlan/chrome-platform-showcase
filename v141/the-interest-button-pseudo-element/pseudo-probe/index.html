Probe the selector, then look for the button

Two layers, probed separately so neither can fake the other. First the parser: does CSS.supports("selector(::interest-button)") hold? Then the observable effect: the link below carries interestfor and a real ::interest-button style block — getComputedStyle(el, "::interest-button") reports whether those declarations actually apply to a generated box.

Recent Chrome builds (verified on Chrome 153) ship this enabled. If the probe reports no support on yours, enable chrome://flags/#enable-experimental-web-platform-features and relaunch, or launch with --enable-blink-features=HTMLInterestForInterestButtonPseudo (the exact runtime flag). The base interestfor attribute has its own demo under v133; this feature is only the tappable pseudo-element.
