Styling inspector

::interest-button is a fully styleable, tree-abiding pseudo-element. It inherits from its originating element and is generated as if it were the element's following sibling. Build a rule with the controls. The page applies it to a live link and button, prints the exact CSS, and reads back getComputedStyle(el, '::interest-button') with the measured box, so you see what the browser really did.

The rule being applied

getComputedStyle(link, '::interest-button')

"width" is the used value when a box exists and auto when none is generated. "Link grew by" compares the link's rect with its text range. Contrast is measured on the computed colours, and a transparent background falls back to the preview background.

what to notice

  • The only opt-in is content. Choose content: none and the box disappears, but the other declarations still compute.
  • The UA stylesheet's defaults (min-inline-size: 24px, cursor: help, user-select: none, vertical-align: middle) show up under "UA default".
  • With ::after on, the ↗ renders before the ⓘ. The pseudo comes after the element's whole box, including its ::after.
  • a:interest-source::interest-button lets the button reflect state. Hover or focus the link, or tap the ⓘ, and it inverts.
