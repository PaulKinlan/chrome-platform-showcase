The ::interest-button pseudo element

Interest invokers (interestfor) open a hint or hovercard when the user hovers, focuses or long-presses a link or button. On a touchscreen that long-press usually opens the link context menu instead, so showing interest takes two steps. ::interest-button is an opt-in, fully styleable pseudo-element that sits just after any valid interest source. Tapping it shows interest in the originating element, and the link does not navigate.

Behind a flag. ChromeStatus has no shipping milestone for this yet (status "Proposed"). The Blink runtime feature is HTMLInterestForInterestButtonPseudo (status experimental). To try it, either enable chrome://flags/#enable-experimental-web-platform-features or launch Chrome or Canary with --enable-blink-features=HTMLInterestForInterestButtonPseudo. Watch out: in Chromium 153 without the flag, CSS.supports('selector(::interest-button)') already returns true but no box is generated. Every concept here therefore pairs the selector check with a layout measurement that can fail.

concepts

  1. Rendering probe inspection

    Does this browser actually generate the box? This page compares the parser check (CSS.supports), the computed content, and a real layout delta for six originating elements: a valid link, a valid button, a link with a broken interestfor id, a plain link, a <span interestfor>, and a valid link with content: none. Only the valid sources with author content may grow.

  2. Styling playground basic · configuration

    Choose the glyph (ⓘ, ?, ↗, a "Preview" label), its alternative text (/ "" or none), when it appears (always, only under @media (any-pointer: coarse), or never), tap-target size, and the colour treatment. The live stage, the generated CSS and the measured box width all update together.

  3. Touch-friendly link previews practical · composition

    An article whose links have hovercards (popover="hint", implicitly anchored with position-area, interest-delay, :interest-source styling). On coarse pointers an ⓘ appears after each link. Tap the ⓘ to preview; tap the link to navigate. An event log records interest, loseinterest, toggle and hashchange, so you can see that the pseudo-element shows interest without navigating.

  4. Edge cases & migration edge · failure · migration

    Change the source's validity live (break the id, remove the target, swap the element type) and watch the box disappear or come back. See how it is ordered after ::after. Compare a hand-rolled sibling toggletip button, which is a tab stop and needs its own ARIA, with ::interest-button, which is not focusable and not in the accessibility tree. The page also explains what browsers without the feature do instead.

use-case portfolio

  • Basic / canonical: styling-playground, using the spec's own @media (any-pointer: coarse) { a::interest-button { content: "ⓘ" / ""; } } example.
  • Inspection tooling: rendering-probe, a layout-backed support matrix.
  • Practical product use: touch-link-previews, an article with hovercards that work on touch.
  • Edge / failure / migration: edge-cases-and-migration, covering source validity, ordering, accessibility and the toggletip migration.
  • Advanced composition: part of touch-link-previews, which combines interest invokers, popover="hint", implicit anchor positioning, interest-delay and :interest-source. There is no separate route: the pseudo-element has no script API of its own (spec: "intentionally not focusable … nor does it appear in the accessibility tree"), so any composition is a composition of the surrounding interest-invoker stack.

the surface

<a href="/people/ada" interestfor="ada-card">Ada Lovelace</a>
<div id="ada-card" popover="hint">…</div>

/* opt in: UA styles leave content: none, so nothing renders by default */
@media (any-pointer: coarse) {
  a::interest-button { content: "ⓘ" / ""; }
}

Per CSS Pseudo-Elements 4 §4.4, the pseudo-element exists only on valid interest sources. When its content is not none, it generates boxes as if it were a following sibling of the originating element, placed before any ::scroll-button(). It inherits from the originating element. Showing interest in it, or activating it, counts as showing interest in the originating element.
