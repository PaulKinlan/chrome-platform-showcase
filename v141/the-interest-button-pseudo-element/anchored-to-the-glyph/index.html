Anchored to the glyph

::interest-button is fully styleable — including position: absolute. Here each product card puts its ⓘ in the top corner, far from the title link that owns it. The spec sheet is a popover=hint placed with position-area: block-end and no explicit anchor. Per the explainer and WPT, opening it from the ⓘ makes the ⓘ the implicit anchor; hovering or focusing the link anchors it to the link. The readout measures which one this browser actually did.

the composition

.card { position: relative; }                 /* containing block */
.card a[interestfor]::interest-button {
  content: "ⓘ" / "";
  position: absolute; inset-block-start: .5rem; inset-inline-end: .5rem;
}
.spec-card[popover] {                          /* no anchor-name needed */
  inset: auto; margin: 0;
  position-area: block-end;                    /* centred under its implicit anchor */
}
.card:has(a:interest-source) { outline: 3px solid; }

The verdict compares the popover’s horizontal centre with the centre of the link and the centre of the ⓘ (pseudo-elements cannot be measured with getBoundingClientRect(), so the page finds the ⓘ by hit-testing around the card: points over the generated box return the originating link even though they lie outside the link’s own text boxes). WPT interestfor-pseudo-element-popover-anchor-methods also pins that a popover already open from the link does not jump to the ⓘ when the ⓘ is pressed.
