Re-parent with moveBefore()

Much of the "subframe removal" seen on the web is really a move: a responsive layout docks a video player from the sidebar to the main column, or a drag-and-drop board reorders embeds. With appendChild(), moving a connected iframe first removes it. Its teardown events fire (synchronously, in deprecated Chrome), the document is destroyed and the frame reloads, losing its state. Element.moveBefore() moves the frame atomically with no detach, so the deprecation never comes into play and the widget keeps its state.

moveBefore() is feature-detected ('moveBefore' in Element.prototype). It shipped in Chrome 133 and Firefox 144, and is not yet in Safari. If it is missing, its button explains why it is disabled and the appendChild() path still runs.

the pattern

function dock(iframe, target) {
  if ('moveBefore' in Element.prototype) {
    target.moveBefore(iframe, null);   // atomic: no detach, no pagehide/unload, no reload
  } else {
    target.append(iframe);             // remove + insert: teardown events, reload, state lost
  }
}
