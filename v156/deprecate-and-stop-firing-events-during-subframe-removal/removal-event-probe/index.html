v156 · behaviour change · canonical probe

Removal event probe

Put a real same-origin <iframe> on the page with pagehide, visibilitychange and unload listeners, call iframe.remove(), and see exactly which events your browser dispatched, in what order, and whether they ran synchronously inside the remove() call. Then compare an opaque-origin sandboxed frame that cannot script this page.

Behind a flag (developer trial): the new behaviour is the Blink runtime feature OmitSubframeDetachmentEventsOnRemoval. It has no chrome://flags entry and is not covered by --enable-experimental-web-platform-features. Launch Chrome (Canary/Dev recommended; the switch exists in Chromium 156+) with --enable-blink-features=OmitSubframeDetachmentEventsOnRemoval — or equivalently --enable-features=OmitSubframeDetachmentEventsOnRemoval. Without it, Chrome keeps the legacy behaviour and this page says so.

2 · Opaque-origin contrast: sandbox="allow-scripts"

Without allow-same-origin the frame gets an opaque origin and no script access to this page, so it cannot re-enter our DOM. It reports over a transferred MessagePort (always asynchronous); whether its handler ran during remove() is judged by comparing its wall-clock timestamp with the window around the call. Chrome often runs sandboxed frames in a separate process, in which case its events (if any) fire after remove() returns.

reading the result

Legacy (default Chrome, Firefox, Safari): the same-origin frame reports pagehide → visibilitychange → unload, all between the before/after markers, and frameElement.isConnected is still true — the handlers run before the node has actually left this document, which is why they can mutate it mid-removal. HTML Standard / flag on: nothing is reported; the child navigable is destroyed silently. The ChromeStatus entry scopes Chrome's change to subframes that can script an ancestor; at the time of writing the Chromium implementation (Document::DispatchUnloadEvents) gates on "not the main frame", so the flagged build also silences opaque frames — the second panel shows which your build does.
