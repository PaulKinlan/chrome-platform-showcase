v156 · css text-overflow · two-value syntax

Two-value bidirectional scroll

When text-overflow receives two values — text-overflow: "‹ " " ›" — the first string marks inline-start overflow and the second string marks inline-end overflow. At scrollLeft === 0, only the end marker appears; once scrolled into the middle, both start and end markers bracket the visible slice; at the far right edge, only the start marker remains.
