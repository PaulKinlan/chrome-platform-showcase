Breadcrumb & filepath condenser

Code review tools, breadcrumb headers, and command palettes truncate hierarchical strings where a plain … obscures whether the cut happened inside a directory name or at a segment boundary. With text-overflow: " / …" or " → …", the truncation marker preserves the hierarchy separator visually while keeping the full path untouched in the DOM for screen readers, find-in-page, and keyboard disclosure.
