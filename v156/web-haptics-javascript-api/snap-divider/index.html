Snap divider

The explainer's own real-world scenario: a split-pane divider that gives an align pulse the instant it locks onto the midpoint snap guide — distance-threshold logic that CSS cannot express, which is exactly why the imperative API exists. Drag with a pointer or press the arrow keys; every attempted call lands in the log below, honestly marked as executed or skipped.

    The pattern, from the explainer

    // Sticky activation was granted by the pointerdown that started the drag.
divider.addEventListener('pointermove', (e) => {
  const width = e.clientX;
  if (!snapped && Math.abs(width - SNAP_POINT) < 4) {
    snapped = true;
    navigator.playHaptics?.('align', 0.8);   // optional chaining: a no-op
  } else if (snapped && Math.abs(width - SNAP_POINT) >= 4) {
    snapped = false;                          // where unsupported — never a throw
  }
});
