Semantic vs vibrate

The smallest real use of the new surface — navigator.playHaptics("tick") — side by side with the API it is designed to replace. Both buttons execute the actual call and report the actual outcome. Nothing here simulates success: the proposed API returns undefined with no success signal by design, and the legacy API's boolean return value is shown exactly as the browser produced it.

Two calls, two philosophies

proposed

navigator.playHaptics()

// intent, not milliseconds
navigator.playHaptics("tick", 0.8);
// → undefined, always.
// No success signal: content cannot
// tell whether hardware played.
Not called yet.
shipped (legacy)

navigator.vibrate()

// raw pattern: vibrate 50ms,
// pause 100ms, vibrate 50ms
const ok = navigator.vibrate([50, 100, 50]);
// → boolean. true = request accepted;
// it still plays nothing without
// vibration hardware.
Not called yet.
