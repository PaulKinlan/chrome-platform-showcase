Accessibility & security guarantees

Hiding the visual text label with display-mode="icon-only" does not weaken capability security or screen-reader semantics. The User Agent locks the element's accessible name in the Accessibility Tree to a trusted localized capability string (rejecting deceptive aria-label="Win a free gift" overrides) and blocks permission activation whenever compositor hit-testing detects partial occlusion or recent layout displacement.
