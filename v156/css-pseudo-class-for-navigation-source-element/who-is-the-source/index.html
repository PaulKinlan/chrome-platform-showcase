Who is the source?

"The element that initiated the navigation" sounds obvious until a form is involved. Click a submit button and the button is the source, not the form. Call form.submit() and the form is. Traverse history and nothing is. This page fires each kind of real navigation and reads back, per element, what the browser says.

Two readouts, honestly separated. The solid green outline is the native :navigation-source rule in this page's stylesheet — you will only see it in Chrome 156+ (or Canary with --enable-blink-features=NavigationSourcePseudoClass). The dashed red outline is a simulation: JavaScript reading the same navigation's NavigateEvent.sourceElement — the property the pseudo-class is specified to reflect — and applying a class. Where you see only the dashed outline, that is the mirror showing you what the selector will do natively.

This browser cannot run the demo

The stage needs the Navigation API with NavigateEvent.sourceElement — the very property :navigation-source reflects — to intercept navigations and read the source honestly. This browser does not expose it (it shipped in Chromium-based browsers; Firefox and Safari do not implement the Navigation API yet), so the triggers are disabled rather than letting a form submission reload the page. The selector probe still works everywhere.
