v156 · :navigation-source

Selector probe

A brand-new pseudo-class is measurable long before you can see it do anything: the parser either knows the token or it does not, and it tells you in five different ways. Each probe below exercises one exact surface, live, and reports what this browser said.

Ships in Chrome 156. Before that it is experimental: enable chrome://flags/#enable-experimental-web-platform-features in Canary, or launch with --enable-blink-features=NavigationSourcePseudoClass (the runtime flag name; it is also implied by --enable-blink-features=RouteMatching). On browsers older than the flag's introduction — including the Chromium 141 this page was verified on — every probe below honestly reports “unsupported”.

Compound-selector builder

The spec's examples never use :navigation-source bare — they compound it with an element type and often a descendant. Build any of those shapes and test it through CSS.supports('selector(…)').
