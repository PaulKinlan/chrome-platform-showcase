The circle label playground

A circular path has an inside and an outside, and until now text on it could only occupy the side the path direction dictated. Flip side between left and right below — and read the measured geometry, because on browsers without the feature the picture will not change, and this page says so rather than pretending.

Measuring…

Ships in Chrome 156, enabled for everyone. To try it before then, use a build that already carries the implementation (Chrome 156 dev/canary channels) and launch with --enable-blink-features=SVGTextPathSideAttribute — the exact name in Blink's runtime_enabled_features.json5, currently status experimental — or enable chrome://flags/#enable-experimental-web-platform-features. There is no dedicated flags entry. Older builds predate the implementation entirely, so no flag enables it there (this page was built against Chromium 141 and measured no change with the flag). Firefox 152 already ships it; WebKit has it in review.

the markup this drives

<path id="ring" d="M 290,150 A 90,90 0 0,1 110,150 A 90,90 0 0,1 290,150"/>
<text font-size="18">
  <textPath href="#ring" startOffset="0%">TEXT ON A CIRCULAR PATH · </textPath>
</text>

The guide circle runs clockwise from the three o'clock point, so the default side="left" places glyphs on the outside. side="right" is defined as "reverse the path": the text then runs counter-clockwise with its glyphs on the inside — which is what the radial-distance measurement above detects, first glyph centre closer to the circle centre than the radius.
