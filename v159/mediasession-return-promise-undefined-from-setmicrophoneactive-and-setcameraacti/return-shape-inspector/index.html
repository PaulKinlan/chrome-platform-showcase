Return-shape inspector

The whole feature is one change in what two methods hand back. Call them here and the raw return value is dissected: is it a promise at all, from which realm, what does it settle to, and when. On Chrome 158 and earlier this page honestly reports undefined; on Chrome 159+ and Safari 18.4+ it reports a promise fulfilled with undefined.

No flag exists for this change — it is an unflagged WebIDL signature update in Chromium 159 (media_session.idl has no RuntimeEnabled gate on these methods). If you see "not a promise", you are on a pre-159 build; nothing is missing or disabled. Calling these methods needs no permission and starts no capture: it only tells the browser what the page considers its mic/camera state to be.

    what each field means

    • typeof — "undefined" on the old shape, "object" on the new.
    • instanceof Promise — true only when the promise comes from this page's realm; the not-fully-active demo shows a case where the tag says Promise but this is false.
    • [[Class]] tag — Object.prototype.toString.call(value), which is realm-independent.
    • settled as — the result of attaching .then() (only when the value is thenable — never chained blindly). The spec resolves with undefined, so a fulfilled value of anything else would be a bug worth reporting.
    • time — milliseconds from call to settle. Chromium resolves immediately (ToResolvedUndefinedPromise), so expect a microtask; a UA with a capture pause policy could take as long as a permission prompt.
    const value = navigator.mediaSession.setMicrophoneActive(false);
typeof value;                              // "undefined" (≤158) | "object" (159+)
Object.prototype.toString.call(value);     // "[object Undefined]" | "[object Promise]"
if (typeof value?.then === 'function') {   // never call .then() on undefined
  await value;                             // resolves with undefined
}
