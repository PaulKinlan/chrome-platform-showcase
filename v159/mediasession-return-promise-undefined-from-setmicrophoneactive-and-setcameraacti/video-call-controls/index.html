Video-call controls

The reason these methods exist: a conferencing app tells the browser whether its mic and camera are live, and the browser's own UI (Picture-in-Picture window, media controls) can toggle them through the togglemicrophone, togglecamera and hangup action handlers. With Promise<undefined> the app can finally await the browser accepting the new state — and catch it refusing — before updating its own buttons.

2 · What the browser answered

Every toggle (from these buttons or from the browser's own media UI) runs the same function and logs exactly what setMicrophoneActive() / setCameraActive() returned.

    the pattern

    async function setMic(on) {
  micTrack.enabled = on;
  try {
    // Promise in Chrome 159+/Safari 18.4+, undefined before — await handles both.
    await navigator.mediaSession.setMicrophoneActive(on);
  } catch (e) {
    // InvalidStateError: document not fully active (e.g. bfcache / detached).
    micTrack.enabled = !on;           // roll back; the UI must not lie
    throw e;
  }
  micButton.ariaPressed = String(on);
}
navigator.mediaSession.setActionHandler('togglemicrophone', () => setMic(!micTrack.enabled));
