Return-shape probe

The whole change is one word in the IDL: undefined became Promise<undefined>. This page calls navigator.mediaSession.setMicrophoneActive() and setCameraActive() for real and inspects what comes back — the value's type, whether it is a thenable, and how it settles.

3 · What the IDL looks like from script

The return type is not reflected on the function object — length and toString() are identical before and after. Only calling it tells you. That is why the verdict above comes from a call, not from a property check.
