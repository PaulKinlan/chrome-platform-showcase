Connection health monitor

This is what getStats() is for in a product: a media or game client polls it, reads round-trip time and the congestion controller's estimatedSendRate, and picks how much to send. This monitor samples a real session on a timer, drives an optional datagram load so the estimate has something to measure, and picks a video quality tier from the numbers it actually receives. When the browser has no estimate yet (estimatedSendRate is null), the monitor says so and keeps the current tier rather than guessing.

Needs WebTransport.prototype.getStats (Chrome 159, or chrome://flags/#enable-experimental-web-platform-features / --enable-blink-features=WebTransportStats) and an HTTP/3 WebTransport server reachable over UDP. Without a session the dashboard stays empty and tells you why. Sampling pauses while the tab is hidden.

const TIERS = [["1080p", 5e6], ["720p", 2.5e6], ["480p", 1.2e6], ["360p", 0.7e6]];
setInterval(async () => {
  const s = await transport.getStats();
  if (s.estimatedSendRate == null) return;          // no estimate: hold
  let i = TIERS.findIndex(([, bps]) => bps <= 0.8 * s.estimatedSendRate);
  if (i === -1) i = TIERS.length - 1;
  if (s.smoothedRtt > 150 && i < TIERS.length - 1) i++;  // latency guard
  encoder.configure({ bitrate: TIERS[i][1] });
}, 1000);
