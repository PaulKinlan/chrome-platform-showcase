Stats snapshot and member inventory

Open a real session, call transport.getStats(), and see the dictionary exactly as this browser returns it, next to every member the spec defines. The spec lets a browser leave members out (for privacy, or because it does not track them), so "absent" is a real answer here and is shown as one. Chromium's ChromeStatus entry says it exposes no byte or packet totals; this page lets you check that claim against your own browser.

This page needs two things you can check below: a browser with WebTransport.prototype.getStats (Chrome 159, or earlier builds with chrome://flags/#enable-experimental-web-platform-features / --enable-blink-features=WebTransportStats), and an HTTP/3 WebTransport server you can reach over UDP. The showcase has no server of its own: the default is a public echo server, and the feature page shows a 30-line local server. If no session opens, the page shows the real error and stops. It never invents numbers.

stats.datagrams.lostOutgoing;

// Absent ≠ zero: test membership before reading.
if (!("bytesSent" in stats)) {

}
