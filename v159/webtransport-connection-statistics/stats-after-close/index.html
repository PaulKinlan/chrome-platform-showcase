The ledger outlives the connection

A session dies; its story should not. The feature's lifecycle promise is that statistics remain accessible after the connection closes — the post-mortem numbers for your telemetry. This page runs the whole lifecycle against a dead endpoint (construct → fail → keep asking) and records what getStats() does at each step, verbatim.

Needs Chrome 159 or --enable-blink-features=WebTransportStats. The dead endpoint (https://127.0.0.1:44443, nothing listens) makes the lifecycle fully reproducible without a server: the session fails fast, which IS the close we then interrogate. On a build without getStats(), each step honestly records the missing method.

const wt = new WebTransport(dead);
wt.closed.catch(() => {});          // the failure is the fixture

try { await wt.closed; } catch {}
const postMortem = await wt.getStats();  // the spec keeps this readable
report(postMortem.minRtt, postMortem.datagrams.lostOutgoing);
