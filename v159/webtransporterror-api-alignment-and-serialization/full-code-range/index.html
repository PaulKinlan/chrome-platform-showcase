All thirty-two bits of the error code

QUIC application error codes are a full unsigned 32-bit space, and the aligned API carries them end to end: streamErrorCode is an unsigned long, so 4294967295 must survive construction and read back exactly. The sweep below constructs a real error for each boundary value — plus WebIDL's conversion behaviour for -1 and 232, and a custom value of your own.

Ships in Chrome 159 (best-effort lever before that: chrome://flags/#enable-experimental-web-platform-features). The sweep uses whichever constructor form this build accepts — standard first, legacy dictionary as fallback — and labels which one did the work.

const err = new WebTransportError("reset", {
  source: "stream",
  streamErrorCode: 0xFFFFFFFF,       // full unsigned-long range
});
err.streamErrorCode === 4294967295;  // must read back exactly

// WebIDL [EnforceRange] is NOT used here, so -1 and 2**32 convert
