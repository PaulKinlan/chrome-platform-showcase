Every way to construct the error

The spec signature is new WebTransportError(message, {source, streamErrorCode}) — the same shape as DOMException. Chromium shipped the older new WebTransportError({streamErrorCode, message}) dictionary form first, and keeps it for compatibility. The button runs five construction forms for real and tables what this build produced for each: what threw, and what message / source / streamErrorCode came out.

The standard constructor ships in Chrome 159. No dedicated flag is documented for it; on earlier builds the best-effort lever is chrome://flags/#enable-experimental-web-platform-features. Whatever this build does, the table reports it verbatim — including the legacy form doing the work alone on pre-159.
