v159 · svg · path data

Read a path as data, not as string

Paste any d string. The shape renders below (plain SVG — that has always worked), and the inspector calls the real getPathData() on the rendered element to list every segment as the spec's {type, values} objects. Flip the {normalize: true} toggle to watch relative commands, H/V shorthands, S/T smooth curves, and arcs all reduce to absolute M / L / C / Z.

Ships in Chrome 159 behind the SVGPathDataAPI runtime flag until then: launch with --enable-blink-features=SVGPathDataAPI, or flip chrome://flags/#enable-experimental-web-platform-features and relaunch. Without it the shape still renders but the segment table reports the missing method honestly — the decade-old workaround is path-data-polyfill.

code path

const path = document.querySelector("path");
path.setAttribute("d", input.value);

const raw = path.getPathData();                  // segments as authored
const norm = path.getPathData({ normalize: true }); // absolute M/L/C/Z only

for (const seg of raw) {
  console.log(seg.type, seg.values);             // e.g. "a", [20,20,0,1,1,40,0]
}
