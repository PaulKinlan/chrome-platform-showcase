Segment inspector

Type or pick any d string and read it back the way the browser itself understands it: path.getPathData() returns one plain {type, values} object per segment — relative letters, shorthand S/T/H/V, arcs and implicit repeated commands included — and getPathData({normalize: true}) rewrites the same geometry as absolute M, L, C and Z only.

Behind a flag. Blink runtime feature SVGPathDataAPI (status experimental). To run the native path:
  1. enable chrome://flags/#enable-experimental-web-platform-features and relaunch, or
  2. launch Chrome with --enable-blink-features=SVGPathDataAPI (or --enable-experimental-web-platform-features).
Firefox 137+ ships it by default. Without it this page uses a clearly labelled JavaScript fallback parser for the un-normalized view and leaves the normalized view empty — the fallback never claims to be the platform.

    the code

    const path = document.querySelector('path');
const segs = path.getPathData();                 // [{type:'M', values:[10,80]}, {type:'C', ...}, {type:'S', ...}]
const flat = path.getPathData({ normalize: true }); // only M, L, C, Z — absolute coordinates
// Relative letters stay lowercase; implicit "M10 10 20 30" yields M then L;
// arcs normalize to one or more cubic approximations.
