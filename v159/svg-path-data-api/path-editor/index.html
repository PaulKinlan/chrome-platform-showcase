Path editor: every number gets an input

The whole point of structured path data is the read-modify-write loop: getPathData() turns the d string into editable objects, you change a number, setPathData() serializes it back. This page builds its editor UI from the parse — one labelled input per value in every segment — and every keystroke runs the real roundtrip, showing the re-serialized attribute the browser wrote.

Chrome targets the SVG Path Data API for Chrome 159 behind the SVGPathDataAPI runtime flag. On an earlier or unflagged build, launch with --enable-blink-features=SVGPathDataAPI, or flip chrome://flags/#enable-experimental-web-platform-features and relaunch.

code path

const segments = path.getPathData();          // read: string → objects
segments[1].values[1] = 40;                   // modify: plain data, no parser
path.setPathData(segments);                   // write: objects → d attribute

path.getAttribute("d");
// → "M 20 110 L 70 40 L 120 110 Z"           // the browser's serialization
