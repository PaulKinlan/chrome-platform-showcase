Transform and build paths

Two everyday jobs that used to need a path-parsing library. Transform: getPathData({normalize: true}) guarantees every value pair is an absolute point (only M, L, C, Z), so one affine function can scale, rotate and flip any path — arcs and relative shorthand included — before setPathData() writes it back. Build: a chart sparkline constructed straight from numbers as segment objects, never concatenating a string.

Behind a flag. Blink runtime feature SVGPathDataAPI (status experimental). Enable chrome://flags/#enable-experimental-web-platform-features, or launch with --enable-blink-features=SVGPathDataAPI. Without it the transform panel is honestly unavailable (normalization is the browser's job and is not faked here); the sparkline builder falls back to a labelled JS serializer.

    the code
    
    
    // Transform: normalize first, then every pair of values is an absolute point.
const segs = src.getPathData({ normalize: true }).map(({ type, values }) => {
  const out = [];
  for (let k = 0; k < values.length; k += 2) out.push(...matrix(values[k], values[k + 1]));
  return { type, values: out };
});
dst.setPathData(segs);

// Build: segments straight from data — no string concatenation.
line.setPathData(points.map(([x, y], i) => ({ type: i ? 'L' : 'M', values: [x, y] })));
