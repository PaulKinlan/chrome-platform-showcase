Which segment is under the marker?

getPointAtLength() has answered "where is distance d?" since forever — the marker dot below uses it. What it never told you is which segment you are on. getPathSegmentAtLength() answers exactly that with a segment index, which this page cross-checks against the coloured per-segment overlay. Drag the slider across segment joins and past the end of the path to see the boundary behaviour.

The marker (old API) works on every build; the segment index needs Chrome 159 or --enable-blink-features=SVGPathDataAPI. Without it the readout reports the missing method and the overlay stays — nothing pretends to know the index.
