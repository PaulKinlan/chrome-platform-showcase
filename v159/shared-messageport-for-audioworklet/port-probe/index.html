Is there a port on the worklet?

The feature is two attributes that used to not exist: audioWorklet.port on the main thread and the port global inside AudioWorkletGlobalScope. The probe below checks the exact surface on a real AudioContext, then loads a real worklet module and pings the rendering thread — the reply carries sampleRate and currentFrame, values only the global scope can answer with.

Ships in Chrome 159; until then it's behind the AudioWorkletSharedPort runtime flag — launch with --enable-blink-features=AudioWorkletSharedPort or flip chrome://flags/#enable-experimental-web-platform-features and relaunch. Without it the probe reports the missing attribute honestly and nothing round-trips.
