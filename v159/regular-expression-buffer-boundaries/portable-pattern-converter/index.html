Portable pattern converter

The proposal's stated motivation is portability: \A and \z appear in TextMate grammars, YAML/JSON configs, Ruby and PCRE docs, and LLM-written code. But the letters do not mean the same thing everywhere — Python's \Z is everyone else's \z. Paste a pattern, pick the dialect it came from, and get a JavaScript pattern plus the modifier-based fallback, then prove the two are equivalent on a battery of edge-case inputs.

edge cases this page encodes

  • Python \Z → JS \z. Python has no "allow a trailing newline" anchor; its $ without re.M already does that.
  • No u/v flag: Annex B keeps \A as a literal A — the converter always emits the u flag, because dropping it silently changes the meaning instead of failing.
  • Inside a class: [\A] is a SyntaxError in Unicode mode; the converter leaves class contents untouched so the error surfaces.
  • The README's /end\Z/ example omits the u flag, but the spec grammar is [+UnicodeMode]-only — without u that pattern matches a literal "endZ". The equivalence table uses u.
