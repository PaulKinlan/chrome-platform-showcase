Syntax probe

The proposal adds three productions to the Assertion grammar — [+UnicodeMode] \A, \z and \Z. The only honest way to detect that is to hand real pattern strings to new RegExp() and see which ones the engine accepts. This page compiles every grammar case (positive and negative) and compares the engine's answer with what the spec text requires.

why this probe shape

A /\A/u literal in page source would be an early SyntaxError on an engine without the proposal and would stop the whole script — so every pattern here goes through the RegExp constructor as a string. The probe can genuinely come back false: on an unsupporting engine new RegExp('\\A', 'u') throws SyntaxError: Invalid escape. The negative rows (character class, no u flag, escaped backslash) prove the result is not a coincidence of a lenient parser.

function supportsBufferBoundaries() {
  try { new RegExp('\\A\\z\\Z', 'u'); return true; }
  catch { return false; }   // SyntaxError: Invalid escape
}
