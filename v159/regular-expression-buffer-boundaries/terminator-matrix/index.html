\Z terminator matrix

\Z is the lenient end anchor. It matches at the very end of the input, or just before one final line terminator: LF, CR, the pair CR LF, U+2028 or U+2029. This page tests end\Z against the end of the word followed by each suffix. It checks every result against a line-by-line JavaScript port of the spec's CompileAssertion steps for \Z. It also includes look-alike characters that are not ECMAScript line terminators.

Behind a V8 flag until it ships. ChromeStatus lists this feature in the Chrome 159 "Enabled by default" group (Finch V8Flag_js_regexp_buffer_boundaries). It is a V8 feature, with no Blink runtime flag, and --enable-experimental-web-platform-features does not turn it on. To run it today, launch Chrome with --js-flags=--js-regexp-buffer-boundaries (verified in Chrome 153). In builds where V8 marks it staged, chrome://flags/#enable-javascript-harmony turns it on as well. In Chrome 153 that flag does not.

Where does \Z fire?

Choose a suffix to mark every position where a bare \Z matches. It can match at two positions: just before the final terminator, and at the very end.

the spec steps, ported

// Assertion :: \Z  (proposal §1.1.2.1 CompileAssertion)
function specZ(input, e) {
  const n = input.length;
  if (e === n) return true;
  if (e === n - 1 && /[\n\r\u2028\u2029]/.test(input[e])) return true;  // LineTerminator
  if (e === n - 2 && input[e] === '\r' && input[e + 1] === '\n') return true;
  return false;
}
