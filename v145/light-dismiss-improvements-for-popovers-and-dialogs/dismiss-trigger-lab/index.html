Dismiss trigger lab

Open the popover or the closedby="any" dialog, then perform each gesture outside it in the dashed arena. The verdicts come from what your browser actually did — the recorder watches the real toggle/close events and which input event they followed. The two gestures that discriminate old from new are the documented bug fixes: touch scrolling and right-clicking. An in-place press-and-release closes on release under both models (the old pointerdown+pointerup pair completes, and the new model's click fires) — the timeline shows which event actually did it.

Chrome 153: enabled by default (runtime flag LightDismissFromClick, killswitch until M157). On older builds the OLD pointerdown behavior is what you will honestly observe here. Gesture verdicts require real input — this page never synthesises a pass.
