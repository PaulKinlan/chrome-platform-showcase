Badge permission gate

The Badging API was designed to be quiet: navigator.setAppBadge(3) resolves whether or not a badge appears. With macOS attribution, that quietness gains a new rule — no granted notification permission, no badge. The promise still resolves; the badge silently doesn't render, because macOS ties badges to each app's notification authorization. This playground makes the invisible gate visible: real calls, real promise outcomes, and a live permission readout beside them.
