2 · Exact enable steps (macOS only)

  1. Use macOS with Chrome 130 or newer.
  2. Open chrome://flags/#enable-mac-pwas-notification-attribution, set it to Enabled, and relaunch. (Verified flag id from Chromium's about_flags.cc; the base feature is features::kAppShimNotificationAttribution, so --enable-features=AppShimNotificationAttribution works too. The flag is registered for macOS only — it does not exist on other OSes.)
  3. Install the PWA (omnibox install icon, or Chrome menu → Cast, save and share → Install page as app).
  4. Grant notifications permission in the installed app window — macOS will now also show its own per-app permission prompt for the App Shim.
  5. Trigger a notification (the probe concept can send one) and check Notification Center: it should carry the PWA's name and icon.
  6. Enterprise: if permission is pre-granted via NotificationsAllowedForUrls, additionally deploy a macOS MDM configuration profile granting notification permission to the PWA's bundle ID.
