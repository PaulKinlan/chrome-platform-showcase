Notification Probe

The attribution change is OS-side — the web-facing surface is still the real Notification API. This page exercises it end to end and reports honestly which of the attribution prerequisites (macOS, installed PWA, flag) this environment meets.

Behind a flag, macOS only. On macOS Chrome 130+: enable chrome://flags/#enable-mac-pwas-notification-attribution (base feature AppShimNotificationAttribution — --enable-features=AppShimNotificationAttribution also works) and relaunch, then install the PWA. The flag's state cannot be read from JavaScript — the checklist below marks it as a manual step.
