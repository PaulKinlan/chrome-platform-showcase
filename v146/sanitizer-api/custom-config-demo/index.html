Custom Sanitizer Config

The Sanitizer constructor accepts a configuration object that limits allowed elements and attributes below the already-safe default. Choose a preset for a common use case — comment box, rich-text editor, or plain text only — then edit the test HTML to see what survives each policy.

Sanitizer API not detected (Element.prototype.setHTML / Sanitizer). It ships enabled by default in Chrome and Edge 146+ and Firefox 148+; Safari does not support it yet. Without it this demo uses a simplified JavaScript fallback — not a real sanitizer.

code for each policy

These are the exact objects the live demo passes to new Sanitizer(), in the current SanitizerConfig shape: elements / removeElements / replaceWithChildrenElements, global attributes / removeAttributes, per-element { name, attributes: [...] } entries, plus comments and dataAttributes. The older attributes: { href: ['a'] } dictionary shape throws a TypeError in the shipped API.

// Comment box — bold, italic, links with href only
const commentSanitizer = new Sanitizer({
  elements: ['b', 'i', 'em', 'strong', 'br', { name: 'a', attributes: ['href'] }],
  replaceWithChildrenElements: ['p', 'h1', 'h2', 'h3', 'ul', 'ol', 'li', 'div', 'span'],
  comments: false,
});
output.setHTML(commentHTML, { sanitizer: commentSanitizer });

// Rich text editor
const richSanitizer = new Sanitizer({
  elements: [
    'h1', 'h2', 'h3', 'p', 'br', 'ul', 'ol', 'li',
    'b', 'i', 'em', 'strong', 's', 'code', 'pre',
    { name: 'a', attributes: ['href'] },
    'table', 'thead', 'tbody', 'tr',
    { name: 'th', attributes: ['colspan', 'rowspan'] },
    { name: 'td', attributes: ['colspan', 'rowspan'] },
  ],
  attributes: [],        // dataAttributes needs a global attributes list,
  comments: false,       // otherwise new Sanitizer() throws TypeError
  dataAttributes: false, // "Invalid Sanitizer configuration".
});

// Strict — links only
const linkSanitizer = new Sanitizer({
  elements: [{ name: 'a', attributes: ['href'] }],
  replaceWithChildrenElements: ['b', 'i', 'em', 'strong', 'p', 'h1', 'h2', 'h3', 'ul', 'ol', 'li', 'div', 'span'],
  comments: false,
});

// Plain text: no elements. Elements not listed are removed WITH their content,
// so keep text by unwrapping common wrappers explicitly.
const textOnlySanitizer = new Sanitizer({
  elements: [],
  replaceWithChildrenElements: ['b', 'i', 'em', 'strong', 'a', 'p', 'h1', 'h2', 'h3', 'ul', 'ol', 'li', 'div', 'span'],
  comments: false,
});
console.log(textOnlySanitizer.get()); // normalised config (names + namespaces)
