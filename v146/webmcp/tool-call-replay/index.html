Tool call replay

A staged conversation: a fictional in-page assistant takes natural-language prompts and picks one of the page's WebMCP tools. The tools are registered with document.modelContext.registerTool(), discovered with getTools() and run with executeTool(), so the trace shows real resolved values and real rejections: a tool that throws, input that fails its schema, and a call cancelled by a deadline. The assistant's tool choice is a keyword stand-in for a model.

// The page registers tools on Document (not navigator):
await document.modelContext.registerTool({
  name: "addToCart",
  description: "Add one or more units of a product to the shopping cart",
  inputSchema: { type: "object",
                 properties: { sku: { type: "string" }, qty: { type: "integer" } },
                 required: ["sku", "qty"] },
  async execute({ sku, qty }, { signal }) { return cart.add(sku, qty); },
});

// An in-page agent discovers and calls them:
const tools = await document.modelContext.getTools();
const tool = tools.find((t) => t.name === "addToCart");
const json = await document.modelContext.executeTool(tool, { sku: "french-press", qty: 2 },
                                                     { signal: AbortSignal.timeout(5000) });
// json is the JSON-stringified return value. A throwing execute() rejects with OperationError.
