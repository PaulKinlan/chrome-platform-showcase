v154 · scroll-marker-group modes

A carousel that declares its mode

The carousel below is real: its dots are ::scroll-marker pseudo-elements the browser generates, working in Chrome since 135. Pick a declaration and the page rewrites the one property, then reads back what the cascade actually did — on a browser that rejects a mode keyword, the fallback is not a guess, it is visible in the computed value.

The mode keywords change semantics, not pixels: in Chrome 154, tabs turns this dashed strip into a tablist with roving focus and links keeps it a navigation list. Ship state and focus order cannot be read from script, so this page shows you the parse result and hands the keyboard to you — the side-by-side reference page lets you feel both focus orders in any browser. Measured through the DevTools accessibility tree on the Chromium 141 this page was built with: the marker group is exposed as a tablist with five tab children whatever the computed mode says — the keywords parse there, but do not yet drive the semantics. Which means 154 is a change for existing carousels too: links is the default, so a marker group that declares no mode switches from today's tablist to a navigation list of links unless its author opts into tabs.

The carousel

Slide one

The dots under this scroller are not elements. They are generated by scroll-marker-group on the scroller and ::scroll-marker on each slide.

Slide two

Activating a marker scrolls its slide into view — no JavaScript in this page moves the scroller.

Slide three

The active marker matches :target-current and flips to black. Scroll by hand and watch it follow.

Slide four

In links mode each marker is its own tab stop. In tabs mode only the active one is, and arrow keys move between them.

Slide five

Same pixels either way — the mode keyword only changes what the markers are to keyboard and assistive-tech users.

Focus journal

    
Click into the page and press Tab (and, in tabs mode on Chrome 154, arrow keys inside the marker strip). Every focus change the document reports lands here, so you can watch how many stops the marker strip costs. Browsers differ in how they attribute focus on a pseudo-element — some report the originating slide, some the scroller — and the journal shows exactly what yours says rather than papering over it.
