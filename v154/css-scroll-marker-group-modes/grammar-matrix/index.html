v154 · scroll-marker-group modes

The grammar, measured

CSS Overflow 5 gives scroll-marker-group the grammar none | [ [ before | after ] || [ links | tabs ] ]. The double bar means position and mode can appear together in either order, or either can stand alone. Which of those forms this browser's parser actually accepts is a question CSS.supports answers exactly — including the forms it should refuse.

The mode keywords ship for all users in Chrome 154. Earlier: launch with --enable-blink-features=CSSScrollMarkerGroupModes, or --enable-features=CSSScrollMarkerGroupModes, or turn on chrome://flags/#enable-experimental-web-platform-features. On the Chromium 141 this page was built with, the two-keyword forms below already parse and the bare and reversed forms do not — that split is the delta this table makes visible.

The serialization tell

The spec says the computed value is the specified keyword(s) — and once a browser understands modes, a plain after can come back from getComputedStyle carrying the default mode with it. Set a declaration on a live probe element and read both what the declaration block stored and what the computed style reports.
