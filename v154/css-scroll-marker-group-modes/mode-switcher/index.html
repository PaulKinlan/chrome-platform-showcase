The grammar, applied live

what the readouts mean

Three facts, three shipping stages. A browser can accept a keyword in the parser before it implements the behaviour behind it. The readouts above only prove the first stage: parsing and serialization. Whether links and tabs actually change the marker group's roles and keyboard model is a separate question these values cannot answer — the semantics inspector covers what is and is not measurable from a page, and the computed value is still worth watching: a browser with modes implemented serializes the mode keyword even when you omit it, so plain after computes to after links.

/* Chrome 154 grammar */
scroll-marker-group: none | [ [ before | after ] || [ links | tabs ] ]

/* Every combination this page can apply */
.carousel { scroll-marker-group: after; }        /* position only — mode defaults to links */
.carousel { scroll-marker-group: after links; }  /* explicit default */
.carousel { scroll-marker-group: after tabs; }   /* tablist semantics */
.carousel { scroll-marker-group: tabs; }         /* mode only — valid per grammar (|| lets
                                                    either component be omitted) */
.carousel { scroll-marker-group: none; }         /* no marker group at all */
