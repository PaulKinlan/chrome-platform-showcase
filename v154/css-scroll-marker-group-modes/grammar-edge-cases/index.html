Grammar edge cases and the cascade

A new keyword in an old property is a cascade question before it is a feature question. The matrix below runs the full value space — spec-valid, spec-invalid, and reordered — through three separate oracles, and the second demo shows the one behaviour you rely on when shipping this to real users: an unparseable declaration is dropped whole, and the declaration above it wins.

The cascade safety net, live

The carousel below is styled by the rule shown — edit it with the checkboxes. When the mode declaration doesn't parse in this browser, CSS error recovery throws away that one declaration, and whatever is left decides whether you still get markers at all.

/* The shipping pattern: declare the fallback first, the mode second. */
.carousel {
  scroll-marker-group: after;       /* Chrome 135+: markers, no mode        */
  scroll-marker-group: after tabs;  /* Chrome 154+: parsed, replaces line 1 */
}
/* A pre-154 parser drops ONLY the second declaration. Ship both lines and
   every Chrome since 135 keeps its marker group. Ship only the second and
   pre-154 browsers get no markers at all — the demo above proves it. */
