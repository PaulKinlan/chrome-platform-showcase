CSS scroll-marker-group modes

A carousel dot and a tab look the same and behave nothing alike. The scroll-marker-group property gains two keywords — links and tabs — that tell the browser which of the two accessibility contracts a marker group should honour: a navigation list of sequential links, or a WAI-ARIA tablist with roving focus, implicit tabpanel roles, and inactive content pruned from the accessibility tree.

    The full value matrix — valid, invalid, and reordered — against CSS.supports, setProperty, and computed style. Then the part that matters for shipping today: an invalid mode declaration is dropped whole, so the base declaration above it keeps working.

    The spec's own advanced composition: a continuous list fragmented by columns, each generated ::column emitting its own marker, with tabs mode assigning tabpanel through the column's originating element. Pages of tabs with zero wrapper markup.

why it shipped

::scroll-marker-group shipped in Chrome 135 with one interaction model baked in. But its two biggest use cases pull in opposite directions: a table of contents wants every marker reachable with Tab, like anchor links; a tabbed carousel wants one tab stop and arrow keys, like a tablist, or twenty dots become twenty Tab presses. Authors picking the pseudo-element for tabs also had no way to get tablist/tab/tabpanel semantics or inactive-panel pruning without giving up and rebuilding the whole thing in ARIA.

The mode keywords make the choice explicit and hand both behaviour sets to the browser: links is the navigation-landmark contract and the default; tabs is the full WAI-ARIA tabs pattern — roving tabindex, focus scope into the active panel, accessibility-tree pruning of inactive panels — with no script.

the syntax

/* Grammar: none | [ [ before | after ] || [ links | tabs ] ] */

.toc-scroller  { scroll-marker-group: before links; } /* nav + link semantics */
.tab-scroller  { scroll-marker-group: after tabs; }   /* tablist + tab + tabpanel */
.plain         { scroll-marker-group: after; }        /* mode omitted → links */
