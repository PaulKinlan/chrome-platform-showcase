Links vs tabs, contract by contract

The two modes are two complete accessibility contracts. This page splits them into their individual promises, measures every one a page can measure, and — where a promise lives only in the accessibility tree — says so plainly instead of guessing. Pseudo-element roles are not readable from JavaScript; anything below labelled manual observation was left for DevTools on purpose.

the contracts

Each spec contract, both modes' promises, and what this browser returned
contractlinks mode promisestabs mode promisesmeasured in this browser
parser accepts the keyword after links parses; links alone parses (grammar: [before|after] || [links|tabs]) after tabs parses; tabs alone parses not measured yet
computed value serializes the mode The computed value is the specified keyword(s); an implementation with modes serializes the mode even when omitted — plain after computes to after links not measured yet
roles group → navigation, markers → link; panels' roles untouched group → tablist, markers → tab, panels → implicit tabpanel manual observation
Pseudo-element roles never surface to page JS. Inspect either carousel above in DevTools > Elements > Accessibility and read the group's role directly.
tab stops & arrow keys every marker is a sequential tab stop, like a list of anchors roving tabindex: only the active marker is a tab stop; arrow keys move within the focusgroup manual observation
Count Tab presses across each marker row above with your keyboard: links mode costs one Tab per marker, tabs mode costs one total.
activation focus activating a marker moves the sequential focus start point to the target panel; focus leaves the marker (like clicking <a href="#target">) focus stays on the marker, like real tabs manual observation
Activate a marker with Enter, then press Tab once and see where you land.
focus scope / tree pruning no pruning; all panel content stays in the accessibility tree Tab from the active marker enters the active panel; inactive panels are pruned from the accessibility tree as if inert manual observation
In the DevTools accessibility tree, check whether the two non-current panels' text still appears under the tabs-mode carousel.		 
/* The same markup, two contracts */
.toc  { scroll-marker-group: after links; } /* nav landmark + sequential links   */
.tabs { scroll-marker-group: after tabs;  } /* tablist + roving focus + pruning  */
