Mixing light, not ink

CSS Color 4 §13.2 is blunt about it: when you want the result of physically mixing two colored lights, interpolate in a linear-light space. This page mixes the same two colors in four spaces at once — gradients above, color-mix() below — so you can see what the gamma curve does to a midpoint.

Checking…

The two lights

in srgb checking

Gamma-encoded sRGB — the historical default. Watch the dark, muddy band in the middle of red → green.

in srgb-linear checking

Linear-light sRGB — already shipping, and the control for this comparison: physically plausible mixing, sRGB gamut.

in display-p3 checking

Wide gamut, but still gamma-encoded — the midpoint dip is still there.

in display-p3-linear checking

The new space: wide gamut AND linear in light intensity — two lamps in a room, on a P3 display.

the code

/* Spec §13.2: "In some cases, the result of physically mixing two
   colored lights is desired. In that case, the CIE XYZ,
   display-p3-linear or srgb-linear color spaces are appropriate,
   because they are linear in light intensity." */

background: linear-gradient(in display-p3-linear, red, green);
color: color-mix(in display-p3-linear, red 50%, green);
