The predefined-space matrix

CSS Color 4 defines exactly ten predefined color spaces for color(): seven RGB spaces and three XYZ variants. This page asks your browser about each one twice — once with CSS.supports() for the parser's answer, once through getComputedStyle() for the serialization the object model actually gives back.

display-p3-linear ships in Chrome 144. On earlier builds the row below honestly reads unsupported — the Blink runtime feature ColorSpaceDisplayP3Linear ships enabled by default from 144, and builds before that don't contain the implementation, so no flag or origin trial can turn it on there. Use Chrome/Chromium 144+ (Canary today) to see the row flip.

space CSS.supports("color: color(<space> 1 0 0)") computed serialization of color(<space> 0.25 0.5 0.75) swatch

The serialization column is the observable effect, not just a syntax check: per §16.5, computed color() values come back lowercase, space-separated, in the same color space they were declared in. An unsupported space never reaches the computed style at all — the declaration is dropped and the element keeps its inherited color, which is what the third column reports for it.
