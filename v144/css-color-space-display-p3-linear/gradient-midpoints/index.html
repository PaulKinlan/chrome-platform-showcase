Gradient Midpoints

Linear-light spaces exist for one big practical reason: interpolation. Averaging gamma-encoded numbers produces midpoints that are too dark — the classic muddy zone in a green→red gradient. Interpolating in display-p3-linear averages light energy instead. This page probes whether your browser accepts the new space in gradient in … syntax and color-mix(), then renders the comparison live.

… color(display-p3-linear 1 0 0) as a color value
… linear-gradient(in display-p3-linear, red, lime) as an interpolation space
… color-mix(in display-p3-linear, red, lime) as a mixing space

This browser rejects display-p3-linear (shipped enabled-by-default in Chrome 144 — no flag or origin trial exists for it). Hatched bars mark the declarations the browser refused; the bars that do render use only the spaces your browser accepts, so nothing below fakes the new feature.

50/50 mixes

The same effect, one number at a time: color-mix() of the selected endpoints at 50% in each space, with the browser's computed result under each chip.

the API

/* endpoints in the new space — valid wherever <color> is valid */
background: linear-gradient(
  color(display-p3-linear 0 0.69 0),   /* same light as display-p3 0 0.85 0 */
  color(display-p3-linear 0.79 0 0));

/* the new space as the interpolation space itself */
background: linear-gradient(in display-p3-linear, red, lime);
color: color-mix(in display-p3-linear, red, lime);
