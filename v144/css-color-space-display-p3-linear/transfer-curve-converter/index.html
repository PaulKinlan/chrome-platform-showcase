Transfer Curve Converter

The only difference between display-p3 and display-p3-linear is the transfer function — the same piecewise curve sRGB uses. This tool walks the curve: pick a linear-light value, read the gamma-encoded equivalent, and (on Chrome 144+) verify the math against the browser's own conversion via relative color syntax.

This browser can't do the conversion natively — display-p3-linear shipped enabled-by-default in Chrome 144 (no flag, no origin trial). The curve and numbers below are computed by page JavaScript implementing the spec's transfer function; they are labelled as JS math, not browser output, and the browser cross-check is marked unavailable rather than faked.

the API

/* the browser converts between the two spaces for you —
   relative color syntax, Chrome 119+, space keyword new in 144 */
.encoded-from-linear {
  color: color(from color(display-p3-linear 0.5 0.5 0.5) display-p3 r g b);
  /* → color(display-p3 0.7354 0.7354 0.7354) */
}

/* the transfer function display-p3 applies on top of linear light */
/* E = L ≤ 0.0031308 ? 12.92·L : 1.055·L^(1/2.4) − 0.055 */
