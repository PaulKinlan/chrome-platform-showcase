Gamut Edges & Fallback

What happens off the happy path? CSS Color 4 says color() components are not clamped at parse time — 1.25 and -0.1 are legal, meaningful values. This page runs the edge probes live: out-of-range components, none channels, a matrix-checked conversion from sRGB, and the @supports pattern for honest fallbacks in older browsers.

display-p3-linear shipped enabled-by-default in Chrome 144 — no flag, no origin trial, no hardware or permission requirement. In this browser every probe below reports the real parse result (mostly "rejected"); that, plus the working @supports fallback at the bottom, is the demo.

the API

/* out-of-range is legal — components are not clamped at parse */
color: color(display-p3-linear 1.25 -0.04 0);

/* missing channels */
color: color(display-p3-linear none 0.5 0.5);

/* honest fallback for pre-144 browsers */
.hero { background: color(display-p3 0.24 0.53 0.94); }
@supports (color: color(display-p3-linear 1 0 0)) {
  .hero { background: color(display-p3-linear 0.047 0.24 0.87); }
}
