v144 · css color space display-p3-linear

The linear swatchboard

The canonical use: write color(display-p3-linear r g b / a) and let the browser resolve it. The components here are light intensities, not the gamma-shaped numbers you are used to — which is why the mid-grey preset does not look mid at all.

On a browser without the color space, the left swatch is deliberately hatched and labelled — the declaration is dropped by the CSS parser and nothing is painted. That is the honest state, and it is exactly what your users on Chrome < 144 would see if you shipped this value without a fallback declaration.

the code

/* Linear-light components: proportional to emitted light. */
.swatch { background: color(display-p3-linear 0.3081 0.014 0.0567); }

/* Progressive enhancement — give older browsers a fallback first: */
.swatch {
  background: rgb(165 5 66);                            /* every browser */
  background: color(display-p3 0.591 0.123 0.264);      /* Chrome 62+   */
  background: color(display-p3-linear 0.3081 0.014 0.0567); /* Chrome 144+ */
}
