Linear-Light Swatches

Same three numbers, two very different colors. display-p3-linear stores light energy, not perceived brightness — so 0.5 0.5 0.5 renders as the grey your monitor emits at half energy, which looks much brighter than "half way to white". Drive the sliders and compare against gamma-encoded display-p3.

This browser does not parse color(display-p3-linear …). It shipped enabled-by-default in Chrome 144 — there is no flag or origin trial to turn on, and it needs no special hardware, permission, or secure context; earlier Chrome versions and other engines simply have not implemented it yet. The hatched chips below mark where the browser refused the value; nothing here is simulated.

the grey ladder

Nine greys, 0.1 → 0.9, rendered in both spaces. In the linear row, everything above ~0.2 already looks light — because a display's response is roughly value2.2, half the energy is nowhere near half the lightness.

the API

/* gamma-encoded Display P3 — what you had since Chrome 62 */
color: color(display-p3 0.5 0.5 0.5);

/* linear-light Display P3 — new in Chrome 144 */
color: color(display-p3-linear 0.5 0.5 0.5);
/* renders like display-p3 0.735: same energy, honest numbers */
