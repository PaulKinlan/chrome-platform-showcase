The gamma decoder

The entire difference between display-p3 and display-p3-linear is one transfer function. This tool decodes any display-p3 color channel by channel into its linear-light twin — and, where the browser supports the new space, proves the two notations are the same color using relative color syntax.

The check asks the browser to convert the linear color back to display-p3 itself — color(from color(display-p3-linear cl…) display-p3 r g b) — and compares the result against your gamma sliders. It can only run where display-p3-linear parses; anywhere else this section reports unsupported rather than pretending.

the code

// display-p3 uses the sRGB transfer function over P3 primaries.
// Decoding a gamma component to linear-light (css-color-4 sample code):
function p3GammaToLinear(c) {
  const a = Math.abs(c);
  return (c < 0 ? -1 : 1) *
    (a <= 0.04045 ? a / 12.92 : Math.pow((a + 0.055) / 1.055, 2.4));
}

/* The spec's own worked pair — the same color twice: */
color: color(display-p3        0.591  0.123 0.264);
color: color(display-p3-linear 0.3081 0.014 0.0567);
