MSE playback pipeline

This is the pipeline Chrome 152 actually ships: an ISO-BMFF file whose audio track is an iamf sample entry, appended through a Media Source Extensions SourceBuffer. The samples are Chromium's own IAMF test assets — alternating sine waves, in a stereo mix and a 7.1.4 mix, Opus substreams, muxed with an H.264 video track that visualises which channel is sounding. Every step below reports its real outcome; nothing is simulated.

Availability: needs Chrome 152+ with the IamfAudioDecoding media feature (no chrome://flags entry — relaunch with --enable-features=IamfAudioDecoding on a build compiled with media_use_iamf_tools). On anything else, step 2 fails with a real NotSupportedError and the page says so — it never fakes playback.

Run the pipeline

iamf_alternating_sine_waves_stereo.mp4

  1. isTypeSupported('video/mp4; codecs="avc1.640028, iamf.000.000.Opus"')
  2. fetch the sample from this site (/samples/)
  3. MediaSource sourceopen
  4. addSourceBuffer(mime)
  5. appendBuffer → updateend
  6. endOfStream → duration & buffered range
  7. play() from your gesture — audio is decoded IAMF

what the samples contain

Both files declare iamf.000.000.Opus: primary_profile 000 (Simple), additional_profile 000, Opus-coded substreams — read straight out of their iacb configuration box. The 7.1.4 file carries a 12-channel (7.1.4) mix presentation that the IAMF decoder renders down to your actual output layout; the stereo file is a plain two-channel mix. They come from Chromium's media/test/data (BSD-licensed) and are served from this site, so the fetch is same-origin. If the fetch itself fails you'll see a labelled “sample unreachable” state with a retry.

code path

const mime = 'video/mp4; codecs="avc1.640028, iamf.000.000.Opus"';
if (!MediaSource.isTypeSupported(mime)) throw new Error("no IAMF decoder");
const ms = new MediaSource();
video.src = URL.createObjectURL(ms);
await new Promise(r => ms.addEventListener("sourceopen", r, { once: true }));
const sb = ms.addSourceBuffer(mime);
sb.appendBuffer(await (await fetch(url)).arrayBuffer());
