The per-path verdicts under each row are a local pre-check that mirrors Chromium's IsValidPath (must start with /, must not start with //, must not be empty, must not itself parse as an absolute URL). It is not the API: an invalid path makes the real add() throw TypeError: “Arguments must be root-relative paths.” before anything else happens.





3 · Manifest the first path must reference


Each install path must load an HTML page whose <link rel="manifest"> resolves to a manifest like this. The sub-app's stable ManifestId is the manifest id, falling back to start_url without any hash fragment.
