Adaptive Prompts

The explainer's headline use case: a cloud-gaming UI that must decide whether to tell the player "Press the touchpad". This demo runs that decision against your real controller — preferring a button whose type === "trackpad", degrading to the clearly-labelled legacy vendor-sniffing heuristic when the attribute is absent — then confirms the press live, fires a vibrationActuator dual-rumble pulse if the pad has one, and announces every decision through a live region.

Flag required for the modern path: the type-based decision only activates on a Chrome build containing CL 7760763 launched with --enable-blink-features=GamepadButtonTypes (or chrome://flags/#enable-experimental-web-platform-features). Without it, the demo honestly shows which fallback it used.

the code

function choosePrompt(pad) {
  // Modern path — Chrome 152 GamepadButton.type:
  const trackpadIndex = pad.buttons.findIndex(
    (b) => "type" in b && b.type === "trackpad",
  );
  if (trackpadIndex !== -1) {
    return { line: "Press the touchpad", index: trackpadIndex, basis: "type" };
  }
  // Legacy heuristic — brittle, per-vendor, kept only as a fallback:
  if (/054c|sony|dualsense|dualshock/i.test(pad.id) && pad.buttons.length > 17) {
    return { line: "Press the touchpad", index: 17, basis: "id-sniffing (fragile)" };
  }
  return { line: "Press any button", index: null, basis: "no trackpad identified" };
}
