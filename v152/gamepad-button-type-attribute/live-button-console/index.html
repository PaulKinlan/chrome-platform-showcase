Live button console

Connect a controller and press any button (the Gamepad API only exposes a pad after real input). Every button renders live at ~60Hz: its index, its Standard-Gamepad name, pressed / touched / analog value — and the real button.type string when the GamepadButtonTypes flag is on. When a "trackpad" button exists, the prompt banner switches to the explainer's canonical use case.

GamepadButton.type is not exposed in this browser — the console still shows real index/pressed/value data for any connected pad; the type column will honestly say attribute missing. To classify for real: launch Chrome 152+ with --enable-blink-features=GamepadButtonTypes or enable chrome://flags/#enable-experimental-web-platform-features, then reload.

window.addEventListener("gamepadconnected", () => {
  const poll = () => {
    const pad = navigator.getGamepads().find(Boolean);
    if (!pad) return;
    for (const [i, b] of pad.buttons.entries()) {
      render(i, b.pressed, b.touched, b.value,
             "type" in b ? b.type : "attribute missing");
      if (b.type === "trackpad") showPrompt("Press the touchpad");
    }
    requestAnimationFrame(poll);
  };
  requestAnimationFrame(poll);
});
