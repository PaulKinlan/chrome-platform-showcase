← Gamepad button type attribute

v152 · interactive demo · needs a physical gamepad

Live Button Inspector

Connect any controller and press a button: the page listens for gamepadconnected, then polls navigator.getGamepads() in a requestAnimationFrame loop and renders every button's value, pressed, touched — and the new type attribute when the GamepadButtonTypes flag is enabled.

Flag required for button.type. This browser does not expose GamepadButton.prototype.type, so the type column below reports it honestly as unavailable. The inspector's value/pressed/touched readouts still work without the flag. To try the real attribute:
  1. Launch Chrome Canary with --enable-blink-features=GamepadButtonTypes (the exact runtime_enabled_features.json5 name; it has no dedicated chrome://flags entry), or
  2. set chrome://flags/#enable-experimental-web-platform-features to Enabled and relaunch (command-line twin: --enable-experimental-web-platform-features).
  3. The implementation (CL 7760763) is still in review — a current channel may not include it even with the flag. That is a missing implementation, not a broken demo.

Polling runs only while a gamepad is connected and this tab is visible — the requestAnimationFrame loop pauses on visibilitychange to save battery.

code

window.addEventListener('gamepadconnected', startPolling);
function poll() {
  for (const pad of navigator.getGamepads()) {
    if (!pad) continue;
    pad.buttons.forEach(function (b, i) {
      // b.value, b.pressed, b.touched — and, behind the flag:
      const kind = 'type' in GamepadButton.prototype ? b.type : undefined;
      // kind is "standard" | "non-standard" | "trackpad"
    });
  }
  raf = requestAnimationFrame(poll);
}
