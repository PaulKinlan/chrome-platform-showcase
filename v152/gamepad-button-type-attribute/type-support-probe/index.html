Type Support Probe

The explainer's documented feature-detection is exactly 'type' in GamepadButton.prototype. This page runs that probe (it can and will return false on browsers without the flag), inspects the property descriptor, and then walks the enum vocabulary with a keyboard-driven illustration — clearly labelled as an illustration, never as API output.

In developer trial — behind a flag. The Blink runtime feature is GamepadButtonTypes (status experimental in runtime_enabled_features.json5; no dedicated chrome://flags entry). To get the probe below to pass:
  1. Launch Chrome Canary with --enable-blink-features=GamepadButtonTypes, or
  2. set chrome://flags/#enable-experimental-web-platform-features to Enabled and relaunch (command-line twin: --enable-experimental-web-platform-features).
  3. The Chromium implementation (CL 7760763) is still in review, so even Canary with the flag may not expose the attribute yet — the probe reports whatever is genuinely true in your browser.
