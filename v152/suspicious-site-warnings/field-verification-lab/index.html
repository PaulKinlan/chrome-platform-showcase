Field Verification Lab

No web page can show you this feature — but you can watch it work inside a real Chrome, end to end: force the base::Feature on, enroll in Enhanced protection, watch real-time verdicts arrive in the Safe Browsing internals page, and read the feature's own histogram. Track your progress as you go; it is saved locally in this browser.

Why copy buttons? chrome:// URLs cannot be opened from a web page link — that is itself a Safe Browsing-relevant security boundary. Copy each one and paste it into the omnibox.

the workflow

0 of 5 steps done

1Launch Chrome with the feature forced on

There is no chrome://flags entry and it is not a Blink runtime feature — kSuspiciousSiteWarnings is a browser-layer base::Feature (disabled by default in source, rolled out for Chrome 152), so the command-line switch is the only manual enable path. Quit Chrome fully first.

--enable-features=SuspiciousSiteWarnings
google-chrome --enable-features=SuspiciousSiteWarnings

macOS: open -a "Google Chrome" --args --enable-features=SuspiciousSiteWarnings · Windows: append the switch to the shortcut target. Verify it took effect at chrome://version (command line row).

2Enroll in Enhanced protection

The warning only exists for Enhanced protection users — that tier is what sends real-time URL lookups to Google.

chrome://settings/security

3Watch real-time verdicts arrive

The Safe Browsing internals page streams the live pipeline. Open the URL real-time lookup panel, then browse normally in another tab: each navigation shows its request and the returned verdict — this is the exact channel whose SOCIAL_ENGINEERING + WARN responses trigger the pop-up.

chrome://safe-browsing

4Contrast with a confirmed-threat interstitial

Google maintains a test site whose pages are flagged as confirmed threats, so you can see the red blocking interstitial the suspicious pop-up is designed to be softer than. Honest limitation: there is no public URL guaranteed to return a WARN (suspicious) verdict — Google does not publish a "test suspicious site", so the pop-up itself can only be observed when a real WARN verdict occurs.

https://testsafebrowsing.appspot.com/

(This one is a normal https URL — the landing page is safe and links to the flagged test pages. Expect red interstitials there, not the suspicious pop-up.)

5Read the feature's own histogram

Every real-time lookup records whether a suspicious verdict was received into SafeBrowsing.SuspiciousSiteWarning.VerdictReceived (url_realtime_mechanism.cc). Non-zero counts in the 1 bucket mean this profile has actually received WARN verdicts.

chrome://histograms/SafeBrowsing.SuspiciousSiteWarning
Work through the steps above; your progress is stored in this browser only.
