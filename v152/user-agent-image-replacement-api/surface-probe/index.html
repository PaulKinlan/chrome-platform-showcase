enable it, exactly

  1. Register your origin for the UAImageReplacementAPI origin trial and serve the token (<meta http-equiv="origin-trial"> or the Origin-Trial header), or
  2. launch Chrome 152+ with --enable-blink-features=UAImageReplacementAPI (the exact runtime_enabled_features.json5 name), or
  3. enable chrome://flags/#enable-experimental-web-platform-features and relaunch,
  4. then reload and Re-probe — the three cells flip without any image being replaced, because they read the prototype, not replacement state.
