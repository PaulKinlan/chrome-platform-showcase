Surface Probe

The smallest real use of the proposed surface: check whether this browser exposes replacedByUserAgent, onuareplacestart, and onuareplaceend on HTMLImageElement.prototype, inspect the property descriptors the IDL promises, and read the live boolean off a real in-page image.

Flag / origin trial required: needs a Chrome build containing the implementation (Canary/Dev in the Chrome 152 timeframe) launched with --enable-blink-features=UAImageReplacementAPI, or an origin-trial token once the Chrome 152–157 trial opens. There is no chrome://flags entry, and --enable-experimental-web-platform-features does not cover it (the runtime feature declares no status). The probes below report whatever is really there.

2 · live read from a real image

Not read yet.

The spec contract: a supporting browser returns false for an image whose content is the author's (and true only while UA substitute content is showing). An unsupported browser returns undefined — a third state your code must not confuse with false. Resilient Adoption digs into that.

3 · the rejected alternative

Not probed yet.

The explainer considered a CSS-only pseudo-class and rejected it as the primary API ("not ergonomic to monitor from script"). This probe runs CSS.supports("selector(:replaced-by-user-agent)") so you can see it is not part of what's shipping — expected false everywhere today.

the code

// Feature-detect the exact IDL members — no instances needed.
const supported =
  "replacedByUserAgent" in HTMLImageElement.prototype &&
  "onuareplacestart" in HTMLImageElement.prototype &&
  "onuareplaceend" in HTMLImageElement.prototype;

// The IDL says: [RuntimeEnabled=UAImageReplacementAPI, Measure]
//   readonly attribute boolean replacedByUserAgent;
// Readonly IDL attribute ⇒ accessor with a getter and NO setter:
const d = Object.getOwnPropertyDescriptor(
  HTMLImageElement.prototype, "replacedByUserAgent");

// Event handler IDL attributes ⇒ accessor with getter AND setter:
const h = Object.getOwnPropertyDescriptor(
  HTMLImageElement.prototype, "onuareplacestart");

// On a live element (supporting browsers only):
const img = document.querySelector("img.product-view");
console.log(img.replacedByUserAgent); // false until the UA substitutes content
