Observability contract

This API's shape is mostly about what pages cannot do: trigger replacement, read replacement content, or probe for replacement features. Each card runs a real check against those guarantees in your browser — press each button and read the actual result.

1 · replacedByUserAgent is read-only

The explainer's non-goal: pages never control replacement state. The IDL says readonly attribute boolean — so an assignment must not change the value.

not tried yet

2 · synthetic events carry isTrusted: false

A page can dispatch an event named uareplacestart at any element — but it can never forge a trusted one. Robust code that must distinguish real replacement checks event.isTrusted.

not tried yet

3 · there is no API to request a replacement

Content-driven replacement is an explicit non-goal: no method on the element or document asks the browser to replace an image. The check enumerates the exposed replacement-related members on HTMLImageElement.prototype — observation members only, never a trigger.

not tried yet

4 · quiet by default (anti-fingerprinting)

Events fire only on explicit user intent — a page sitting idle must observe nothing. This card counts uareplace* events since load on an instrumented image; on any browser without a user actually invoking a replacement feature, the honest count stays zero.
