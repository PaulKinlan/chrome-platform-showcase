Coordinated product card

The explainer's scenario, wired with real listeners: when uareplacestart fires on the product image, the card hides its zoom control and the "model wears size M" copy (they'd be wrong for a try-on render); uareplaceend restores them. Pages cannot trigger UA replacement — that's a designed non-goal — so the rehearsal button dispatches synthetic events through the very same listeners, clearly labelled, with isTrusted printed for every event.

The observation surface is not exposed here (no replacedByUserAgent on HTMLImageElement.prototype) — synthetic rehearsal still exercises the listeners below, since addEventListener("uareplacestart", …) works on any target. Real trusted events additionally need the UAImageReplacementAPI origin trial or --enable-blink-features=UAImageReplacementAPI and a user actually using a replacement feature.

const img = document.querySelector("img.product-view");

img.addEventListener("uareplacestart", (e) => {
  card.classList.add("replaced");        // hide zoom lens + size copy
});
img.addEventListener("uareplaceend", (e) => {
  card.classList.remove("replaced");     // replacement reverted or finished
});

// Handle a replacement that happened before this script ran:
if (img.replacedByUserAgent) card.classList.add("replaced");
