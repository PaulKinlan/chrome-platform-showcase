Sticky Per-Axis Table

The explainer's headline case: a table that scrolls horizontally inside its wrapper while the page owns vertical scrolling. position: sticky is constrained by the nearest ancestor that is a scroll container in that axis — so the column headers (top: 0) should ride the page scroll, and the row labels (left: 0) should ride the wrapper's horizontal scroll. That split is only possible when the wrapper is an x-axis-only scroll container: overflow: scroll clip. With the legacy scroll hidden (or a bare overflow-x: auto), the wrapper is a scroll container in both axes, the header row anchors to the wrapper instead, and it scrolls straight off screen with the rest of the box.

what just happened

Choose a mode, press Scroll page into the middle of the table, and watch the black header row. In scroll clip mode (when supported) it pins to the top of the viewport — its vertical sticky ancestor is the page, because the wrapper does not compute to a scrollable value on the y axis. Drag the wrapper sideways and the stone-coloured row labels pin to the left edge — their horizontal sticky ancestor is the wrapper. Switch to scroll hidden or overflow-x: auto and the header stops pinning to the viewport: the wrapper itself became a vertical scroll container (even though it has nothing to scroll vertically), so the header's top: 0 is satisfied while the whole box scrolls away.
