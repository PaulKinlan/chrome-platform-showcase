v152 · CSS Overflow

Single-axis scroll containers

The overflow property now lets a scrollable value combine with clip — for example overflow: scroll clip. Before Chrome 152, that combination was silently coerced: the clip axis computed to hidden, which made the box a scroll container in both axes. Now the box becomes a single-axis scroll container: the clipped axis can never move — not by the user, not by scrollIntoView(), not by script — and position: sticky is constrained per axis by the nearest ancestor that actually scrolls in that axis.

concepts

  1. Computed Value Probe

    Apply real overflow pairs to a live scroller and read back what this browser computes — clip preserved (new) or coerced to hidden (legacy) — then try to script-scroll the clipped axis.

  2. Clipped Carousel vs Hidden Carousel

    Two identical horizontal carousels — scroll hidden vs scroll clip — where scrollIntoView() and script scrolling show why the clip axis staying pinned at 0 matters.

  3. Sticky Per-Axis Table

    A wide data table whose top labels stick to the page scroll and left labels stick to the table's own horizontal scroll — only possible when the wrapper is an x-axis-only scroll container.

  4. Overflow Combination Matrix

    Pick any overflow-x × overflow-y pair, watch the live stage, and see specified → computed values, which coercions still apply (visible → auto), and the resulting scroll-container classification.

why it shipped

Authors have long needed "scrolls in one axis only" — a table that scrolls horizontally while the page owns vertical scrolling, or a carousel that is visually clipped vertically. Emulating it with overflow: scroll hidden was leaky: hidden is still a scrollable value, so the box was a scroll container in both axes. That made position: sticky anchor to the wrong scroller and let scrollIntoView() shift the hidden axis with no way for the user to scroll it back. Combining scrollable values with clip (CSS Overflow Level 3, resolved in csswg issue 8286) fixes both, with a small compatibility risk since scroll clip previously computed to scroll hidden.
