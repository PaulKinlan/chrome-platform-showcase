the exact rules (CSS Overflow Level 3 §3.1)

auto, scroll and hidden are the scrollable values; visible and clip are non-scrollable. If the other axis specifies a scrollable value, a specified visible computes to auto — that coercion is unchanged. What changed: clip now survives next to a scrollable value, and "if only one axis computes to a scrollable value (i.e. the other axis is clip), the box is a single-axis scroll container." Before this, the clip axis computed to hidden, which kept the box scrollable-by-script in both axes.
