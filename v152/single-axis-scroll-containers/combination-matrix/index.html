edge cases worth trying

  • scroll × clip — the new single-axis form. Computed clip is preserved in Chrome 152+; older browsers show the legacy coercion to hidden.
  • scroll × visible — unchanged rule: visible cannot combine with a scrollable value and computes to auto. Single-axis did not change this.
  • clip × visible — always legal, before and after: both compute as specified, and the box is not a scroll container at all.
  • hidden × clip — still single-axis: hidden is a scrollable value (script-only), so the box scrolls on x by script while y is pinned.
  • clip × clip — no scroll container; neither axis can move, even by script.
