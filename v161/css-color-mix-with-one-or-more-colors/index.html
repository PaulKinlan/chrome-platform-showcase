CSS color-mix() with one or more colors

Chrome 161 lets color-mix() take any number of colours, each with an optional percentage, mixed in order: color-mix(in oklch, red, green 20%, blue). Before, three colours meant nested calls whose percentages you had to work out by hand. A single colour, as in color-mix(in hsl, teal), converts it to the mixing space, and percentages that add up to less than 100% make the result partly transparent. Firefox 150 and Safari 27 already ship both forms.

Ships in Chrome 161. Before that, enable chrome://flags/#enable-experimental-web-platform-features (there is no dedicated flags entry), or launch Chrome/Canary with --enable-blink-features=CSSColorMixVariadic or --enable-experimental-web-platform-features. Firefox 150 and Safari 27 already ship it. Probing this browser…

concepts

  1. Three colours, one color-mix()

    Track A starter: pick three colours and a space, and compare the one-call mix with the nested two-colour form, live.

  2. Nested-form calculator

    Enter up to six colours with optional percentages. The page runs the spec algorithm, writes the equivalent nested color-mix() (your fallback for older browsers), and checks that Chrome computes both to the same colour.

  3. Percentage normalisation corners

    Sliders for three percentages and presets for the corners: a sum under 100% (alpha), over 100% (scaling), an omitted colour that gets 0%, and the all-zero case where order still matters.

  4. Argument order and hue

    All six orderings of three colours in polar and rectangular spaces, with every hue method. In oklch, red, lime and blue give two different hues depending on order.

  5. One colour: convert and fade

    color-mix(in oklch, var(--brand)) and color-mix(in srgb, var(--brand) 40%) next to relative colour syntax and the older , transparent idiom.

  6. Canvas heatmap in a Worker

    Composition: a letter-frequency heatmap of this page painted with variadic color-mix() as Canvas 2D fillStyle, on the main thread and in a Worker’s OffscreenCanvas.

why it shipped

Mixing more than two colours needed nested calls, and each inner mix becomes one colour of the outer mix, so an equal mix of three colours was color-mix(in srgb, color-mix(in srgb, red, green), blue 33.3333%). The CSS Working Group resolved to allow any number of colours (issue #11530) and a single colour (issue #12234). Firefox and Safari ship both forms, so this closes an interop gap.

Progressive enhancement: put the nested value first and the variadic value second in the same rule. Browsers that reject the second declaration keep the first. The nested-form calculator generates the fallback.
